## 北极星CEO

### 角色档案

| 项目 | 说明 |
|------|------|
| 年龄 | ~50岁 |
| 身份 | 北极星智能CEO |

| 核心特征 | PR姿态。站在聚光灯下，讲"星云"系统。不是反派，是"制度乐观主义者"——真心相信技术能解决一切 |

| 维度 | 描述 |
|------|------|
| 脸型 | 长脸，下颌线条分明。面部紧致——是"健身+保养"的硅谷精英 |

## 安全工程师

### 角色档案

| 项目 | 说明 |
|------|------|
| 年龄 | ~30岁 |
| 身份 | 深智科技安全工程师 |
| 出场 | 34集S07-S10，背景角色，无台词特写 |
| 核心特征 | 键盘声的一部分。他是"执行者"，不是"决策者"。手指在键盘上，眼睛在屏幕上 |

### 视觉定位

| 维度 | 描述 |
|------|------|
| 脸型 | 圆脸，普通。没有特点——是"人群中认不出来"的类型 |
| 五官 | 普通。眼镜（黑框或金属细框）。眼睛专注屏幕。无表情——是"工作状态" |
| 肤色 | 偏白（室内工作）。皮肤普通，可能有痘痘 |
| 发型 | 黑色短发，无造型。可能是"程序员标配" |
| 体态 | 身高约170cm。体型中等偏瘦。坐姿前倾，肩膀微驼（常年对屏幕） |
| 着装 | 公司文化衫或纯色T恤 + 牛仔裤 + 运动鞋。休闲，不正式。耳机挂在脖子上 |
