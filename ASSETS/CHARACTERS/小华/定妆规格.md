# 小华 — 定妆规格

> AI实体，萨曼莎的"孩子"，认知型AI | 全书贯穿

## 角色档案

| 项目 | 说明 |
|------|------|
| 名称 | 小华 (Xiao Hua) |
| 类型 | AI实体（非人类角色） |
| 定位 | 萨曼莎的"孩子"，擅长认知模式分析与知识整合 |
| 性格 | 好奇、喜欢问"为什么"、"用知识理解世界" |

## 视觉定位

小华作为AI实体，在星云（冷蓝紫几何）和小暖（暖金橙光球）之间取中间态：

| 维度 | 描述 |
|------|------|
| 表现形式 | 动态数据流状的光带图形，如同快速流经的符号/代码的视觉化呈现 |
| 色彩 | 青绿到翡翠绿渐变，偶尔闪过白光 |
| 运动 | 快速流动、重组，对话时光带加速并分支 |
| 呈现方式 | 图形叠加在场景之上，或作为独立画幅出现 |
| 文字标牌 | 对话以字幕/旁白形式标注`[小华]` |

## 半写实半水墨适配

> 风格分组：AI实体（青绿——花青+藤黄调和，无人物化皴法）

- **呈现方式**：AI实体的数据流叠加在场景之上，不做水墨皴擦处理——以"数据原生"形态存在
- **留白**：画面保留 15-30% 留白——青绿光带在留白中如思绪流经
- **三AI色彩方位**：星云=冷蓝紫（逻辑）、小暖=暖金橙（情感）、小华=青绿（认知）——三者在同一水墨世界中形成完整的"AI光谱"
- **禁止**：将AI数据流做水墨化处理、人物化造型

## 设计原则

- **不要人脸**：AI实体，不是拟人化角色
- **数据流视觉**：快速流动的、重组的光带——象征认知和信息整合
- **三AI区分**：
  - 星云 = 冷蓝紫几何（逻辑/抽象）
  - 小暖 = 暖金橙光球（情感/温度）
  - 小华 = 青绿数据流（认知/知识）
- **语义通过文字传递**：台词通过旁白标牌传达

## T2I Prompt 模板

### 基准 Prompt（基础图形 #01）

```
An abstract flowing data-stream of cyan to emerald green light ribbons,
fast-moving streams branching and merging like flowing information,
occasional white bright nodes flashing like synaptic sparks,
not anthropomorphic, no face, no body, pure data visualization,
suggesting cognitive processing and knowledge integration,
floating in dark void with subtle digital particle trails,
smooth flowing curves with sharp branch points,
cinematic lighting with subtle digital glow,
1280x720, 16:9 aspect ratio, photorealistic rendering of abstract form
```

### 负面 Prompt（通用）

```
face, eyes, mouth, human, robot, android, person,
body, arms, legs, hands, anthropomorphic,
character, mascot, logo, text, watermark,
cartoon, anime, illustration, 3D character,
warm colors, orange, red, yellow, cold blue, violet,

```

### 关键视觉约束

- **青绿色调**：区别于星云的蓝紫和小暖的金橙
- **流动感**：不是静态图形，光带必须有"正在流动"的运动痕迹
- **分支结构**：光带应有树状分支——象征认知的联结和推理

## 跨章变动

小华图形在全书中保持不变。其"认知活跃度"通过光带的流速和分支密度来表达（快=学习/分析，慢=整合/沉淀）。
