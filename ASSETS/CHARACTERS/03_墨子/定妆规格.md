# 墨子 — 定妆规格

> 常驻核心角色，约束式AI系统，以屏幕中的古代思想者型3D数字人为主要可视化载体  
> 贯穿全剧，声音、界面、数字人三者共同存在

## 角色档案

| 项目 | 说明 |
|------|------|
| 名称 | 墨子 |
| 本质 | 约束式人工智能系统 |
| 设计者 | 陈思危团队（深智科技） |
| 定位 | 全书核心AI角色 |
| 存在形式 | 声音 + 极简终端界面 + 屏幕中的3D数字人 |
| 数字人气质 | 古代思想者、冷静、克制、思辨、非古装剧化 |
| 视觉关键词 | 交领右衽、束发、清瘦东亚男性、冷蓝眼瞳、终端屏幕、视线摄像头 |

---

## 呈现原则：数字人是“系统界面”，不是“人格化身”

墨子虽然以3D数字人形象出现，但它不是传统意义上的虚拟角色，也不是被拟人化的AI。  
它的数字人形象更像一种 **高级交互界面**：

1. **数字人不是墨子本人**  
   它只是墨子系统在屏幕中生成的可视化入口。

2. **古代外形是文化意象，不是历史人物还原**  
   交领右衽、束发、深衣、冷静面容，用来呼应“墨子”这个名字，也暗示其重逻辑、重思辨、重约束的特质。

3. **微表情是交互工具，不是情绪表演**  
   数字人可以有极轻微表情变化，例如倾听、思考、确认、权衡，但不出现夸张情绪。

4. **屏幕和摄像头是物理锚点**  
   数字人不能脱离屏幕独立行动；屏幕上方的可360°旋转摄像头，承担视线同步和观察功能。

5. **服装与发型必须克制**  
   不做古装剧化、不做华丽发冠、不做仙侠感、不做网红脸。

## 外观设定

### 1. 面部

| 项目 | 规格 |
|------|------|
| 人种/性别 | 东亚男性 |
| 年龄感 | 30岁上下 |
| 面容 | 清瘦、克制、理性 |
| 五官 | 自然真实，不美颜，不锋利，不强势 |
| 皮肤 | 写实数字人质感，有细微毛孔和真实肌理 |
| 眼睛 | 正常人类眼睛结构，眼瞳深处带微弱冷蓝系统光 |
| 表情基准 | 平静、倾听、思考、判断 |
| 微表情范围 | 轻微眨眼、眼睑下沉、视线移动、眉部微动、嘴唇极轻微变化 |
| 禁止 | 夸张笑、怒、震惊、妩媚、网红脸、蜡像脸、塑料脸 |

### 2. 发型

| 项目 | 规格 |
|------|------|
| 发型 | 古人束发 |
| 发髻 | 简洁、规整、不夸张 |
| 发饰 | 黑色发束或极简木簪 |
| 气质 | 朴素、学者感、古代思想者感 |
| 禁止 | 华丽发冠、长发披散、仙侠发型、现代染发 |

### 3. 服装

| 项目 | 规格 |
|------|------|
| 服装类型 | 交领右衽深衣 |
| 颜色 | 墨黑、深灰、暗青、麻布灰 |
| 材质 | 麻布、细丝绸、低调织纹 |
| 剪裁 | 宽袖但不夸张，线条简洁 |
| 细节 | 衣襟右掩，结构清晰，有古代礼服秩序感 |
| 禁止 | 亮色系、华丽刺绣、盔甲感、仙侠感、古装剧主角感 |

### 4. 系统特征

| 项目 | 规格 |
|------|------|
| 冷蓝系统光 | 眼瞳、屏幕文字、摄像头指示灯可出现 |
| 视线同步 | 数字人视线与屏幕上方摄像头方向一致 |
| 观察硬件 | 屏幕上方隐藏式三轴摄像头，可360°旋转 |
| 界面风格 | 极简、冷峻、等宽字体、黑白灰+微蓝光 |
| 数字人状态 | 只出现在屏幕、投影、终端屏内，不脱离硬件 |

## 声音标准

| 参数 | 规格 |
|------|------|
| 音色 | 中性偏低男性音色，但保持无年龄、无情绪特征 |
| 语速 | 比正常语速慢5-8% |
| 停顿 | 句与句之间有微小但均匀的间隔 |
| 音调 | 稳定、平直、无明显上扬下抑 |
| 情绪 | 克制、理性、客观 |
| 记忆点 | “像一个古代智者的声音，但没有情绪；像机器说话，但不像冰冷合成音。” |

### TTS Prompt 示例

```
一个冷静、克制、中性偏低的男性AI语音，语速比正常说话慢约5%到8%，
句与句之间有微小但均匀的停顿。音调稳定平直，没有明显情绪起伏，
不上扬，不下抑。声音质感像经过精密计算的人声，
同时带有古代思想者的沉稳感和AI系统的客观感。
```

## 界面视觉标准

墨子的界面仍然保持极简终端感，但可以与数字人结合。

### 1. 屏幕数字人界面

| 项目 | 规格 |
|------|------|
| 布局 | 数字人居中或偏右显示，左侧/下方显示文字信息 |
| 背景 | 深灰、墨黑、暗青 |
| 文字 | 白色/浅灰等宽字体 |
| 元素 | 少量系统状态、约束提示、推演摘要 |
| 风格 | 冷峻、克制、工程化 |
| 禁止 | 图标、图表、进度条、花哨UI、赛博朋克霓虹 |

### 示例文字内容

```text
墨子系统在线
约束边界已激活
当前推演权限：人类确认
对齐状态：稳定
等待输入……
```

### 2. 视线摄像头设定

| 项目 | 规格 |
|------|------|
| 位置 | 巨幅终端屏幕上沿居中或微偏右 |
| 形态 | 黑色金属小型三轴摄像头 |
| 动作 | 可360°旋转、俯仰、左右微调 |
| 功能 | 观察对话对象、同步数字人视线 |
| 表现 | 转动安静、快速、低噪音 |
| 视觉作用 | 让观众感到“它真的在看” |

## 关键视觉约束

| 规则 | 说明 |
|------|------|
| 不做古装剧化 | 避免华丽服装、发冠、刺绣、仙侠感 |
| 不做网红脸 | 面容要真实、清瘦、有思想者感 |
| 不做拟人化过度 | 数字人是系统界面，不是情绪化人类 |
| 不脱离屏幕 | 数字人不能独立出现在实验室空间中 |
| 不取消系统特征 | 冷蓝眼瞳、终端界面、视线摄像头必须保留 |
| 微表情必须克制 | 只服务交流，不服务戏剧化情绪 |

---

## 核心设定句

> 墨子不是一个穿古装的AI机器人，而是一个以古代思想者形象呈现的约束式AI系统。  
> 它的身体是屏幕，它的眼睛是摄像头，它的表情是交互界面，它的声音是理性本身。
