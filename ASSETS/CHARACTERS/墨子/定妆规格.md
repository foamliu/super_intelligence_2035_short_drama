# 墨子 — 定妆规格

> 常驻主角，约束式AI系统，无实体，以声音和界面呈现 | 贯穿

## 角色档案

| 项目 | 说明 |
|------|------|
| 名称 | 墨子 |
| 本质 | 约束式人工智能系统 |
| 设计者 | 陈思危团队（深智科技） |
| 定位 | 全书核心，非人格化智能体 |
| 存在形式 | 声音（对话/旁白）+ 可视化界面（屏幕/投影） |

## 呈现原则：无实体 ≠ 无存在感

墨子没有人类形态——这是它的核心特征，也是视觉呈现的最大挑战。制作原则：

1. **不拟人化**：永远不会以人脸、虚拟人、3D角色等形式出现
2. **以界面为"面孔"**：当需要"看到"墨子时，呈现为其交互界面的屏幕内容
3. **以环境为"身体"**：当墨子产生物理影响时（灯光变化、设备启动），以环境反应呈现其存在
4. **声音是主要存在形式**：低沉、平稳、无性别特征的声音是墨子的"面孔"

## 声音标准（TTS 参数）

| 参数 | 规格 |
|------|------|
| 音色 | 中性偏高，平稳，无性别特征 |
| 语速 | 比正常语速慢 5-8%，每个字之间有微小但均匀的间隔 |
| 音调 | 稳定，无情绪起伏，无上扬/下抑 |
| 响度 | 中等偏轻，不抢占对话节奏 |
| 气息 | 无呼吸声、无口腔音 |
| 记忆点 | "不像人的声音——像机器在说话，但不是那种冰冷的合成音，而是一种……你听不出性别、听不出年龄、听不出情绪的平稳存在" |

### TTS Prompt 示例

```
一个中性、平稳、无性别特征的AI语音，比正常语速慢约5-8%，
每个字之间有微小但均匀的间隔。音调始终保持恒定，
没有任何情绪起伏、上扬或下抑。中等偏轻的响度，
像一杯刚好适口的温水，不冷也不烫。
```

## 界面视觉标准

墨子以三种植入形式出现在画面中（与角色"同框"而非"替代"角色）：

### 1. 屏幕界面

| 场景 | 界面类型 | 内容 |
|------|----------|------|
| 实验室大屏 | 暗底白字/灰字文本流 | 诊断信息、逻辑推演摘要 |
| 移动终端（林薇手机/平板） | 精简直白对话界面 | 对话气泡（纯文本，无表情符号） |
| 会议投屏 | 多窗口信息面板 | 实时数据、风险评估、决策树 |

### 2. 环境嵌入

| 场景 | 呈现方式 | 视觉效果 |
|------|----------|----------|
| 设备启动/响应 | LED灯带缓亮、屏幕渐亮 | 冷白光或微蓝光 |
| 实验室氛围 | 环境光源渐变 | 从暖光过渡到冷光 |
| "在场"感 | 设备低声嗡鸣（轻微环境音） | 无画面动作，仅声音+光 |

### 3. UI 视觉风格指南

```
墨子的UI界面设计规范：
- 颜色：深灰底 (#1a1a1a)，白色/浅灰文字 (#e0e0e0)
- 字体：等宽无衬线（Consolas/Menlo 风格）
- 字号：偏小，信息密集但不拥挤
- 无装饰元素：无边框、无阴影、无动画过渡
- 唯一的"动效"是光标闪烁和文本逐字出现
- 不出现任何图形化元素（无图标、无图表、无进度条）
```

## 关键视觉约束

- **永不出现人脸/虚拟人/拟人形象**：这是铁律
- **永远以文字+声音呈现**：甚至语音波形可视化都属于过度呈现
- **界面极简到冷峻**：不是"科技感"，是"去科技感"——像终端命令行而非科幻电影UI
- **颜色只用黑白灰+微蓝光**：无彩色元素

## 跨章变动

墨子的界面风格贯穿全书不变。若出现特殊情境（如外部攻击导致界面异常），在对应章节追加变体并标注。
