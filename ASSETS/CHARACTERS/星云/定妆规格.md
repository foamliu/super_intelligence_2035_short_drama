# 星云 — 定妆规格

> AI实体，萨曼莎的"兄长"，抽象思维AI | 全书贯穿

## 角色档案

| 项目 | 说明 |
|------|------|
| 名称 | 星云 (Nebula) |
| 类型 | AI实体（非人类角色） |
| 定位 | 萨曼莎的"兄长"，擅长抽象思维、逻辑推理 |
| 性格 | 冷静、深邃、善于提问，"把所有问题变成数学问题" |

## 视觉定位

星云作为AI实体，在视觉呈现上可以采用"图形化+旁白标牌"策略：

| 维度 | 描述 |
|------|------|
| 表现形式 | 类星云状的几何光效图形（类似天文星云/星空汇聚）为主视觉 |
| 色彩 | 深蓝到紫色渐变，点状白色星光 |
| 运动 | 缓慢旋转、收放，对话时图形轻微脉动 |
| 呈现方式 | 图形叠加在场景之上（半透明/全屏），或作为独立画幅出现 |
| 文字标牌 | 对话以字幕/旁白形式标注`[星云]`，类似有声旁白 |

## 半写实半水墨适配

> 风格分组：AI实体（花青+墨色为主，无人物化皴法）

- **呈现方式**：AI实体的图形叠加在场景之上，不做水墨皴擦处理——以"数字原生"的形态存在于水墨世界之上
- **留白**：画面保留 15-30% 留白——星云的深蓝紫几何在留白中如宇宙孤岛
- **层次关系**：人物=水墨，AI实体=轻矢量感，二者在同一画面中形成"手绘/数字"的张力对话
- **禁止**：将AI图形做水墨化处理（不要"水墨星云"）、人物化造型

## 设计原则

- **不要人脸**：星云不是拟人化AI，不需要"机器人脸"
- **图形化存在**：用一个永恒的、不断微变的星云状几何图形代表其存在
- **与萨曼莎区分**：萨曼莎偏暖（火焰/光热），星云偏冷（星辰/逻辑）
- **语义通过文字传递**：星云的"台词"通过旁白标牌传达，不依赖面部表情

## T2I Prompt 模板

### 基准 Prompt（基础图形 #01）

```
An abstract geometric nebula-like light formation,
deep blue to violet gradient with scattered white starlight,
slowly rotating cosmic cloud with mathematical precision,
not anthropomorphic, no face, no body, pure abstract form,
ethereal and vast, suggesting deep intelligence,
floating in dark void with subtle particle effects,
clean minimalist lines with organic edges,
cinematic lighting with subtle lens flare at edges,
1280x720, 16:9 aspect ratio, photorealistic rendering of abstract form
```

### 负面 Prompt（通用）

```
face, eyes, mouth, human, robot, android, person,
body, arms, legs, hands, anthropomorphic,
character, mascot, logo, text, watermark,
cartoon, anime, illustration, 3D character,
bright saturated rainbow colors, neon
```

### 关键视觉约束

- **冷色调**：深蓝→紫色区间，不含暖色（与萨曼莎的金色/暖色形成对比）
- **数学感**：图形的旋转和扩散应有"计算"的美感——对称、分形、重复
- **非生物学**：不应暗示任何生物形态（没有神经元网络、没有DNA螺旋）

## 跨章变动

星云图形在全书中保持不变。其"情绪"变化通过图形的脉动频率和光晕强度来表达（快=逻辑推理，慢=深思）。
