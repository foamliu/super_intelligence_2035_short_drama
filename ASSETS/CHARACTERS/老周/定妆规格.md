## 视觉定位

| 维度 | 描述 |
|------|------|
| 脸型 | 圆脸偏瘦，颧骨突出，下颌线条因消瘦而清晰。脸上的皱纹不是年龄，是二十二年工厂留下的——眼角细纹、额头横纹、鼻翼到嘴角的法令纹深而实 |
| 五官 | 眉毛粗短但眉尾稀疏，单眼皮，眼角微微下垂，眼下有明显的浮肿和黑眼圈（长期熬夜跑车）。鼻子直而普通，嘴唇干裂偏薄，常抿着。眼神里有疲惫但不是麻木——是一种"还在撑着"的残余力量 |
| 肤色 | 偏黑黄（户外跑车+多年车间），肤质粗糙，毛孔可见 |
| 发型 | 黑色短发，发际线后退（M型早期），鬓角几根白发，不打理——不是不讲究，是没精力讲究 |
| 体态 | 身高170cm左右，体型偏瘦但肩背宽（工人底子），有轻微的驼背——常年窝在驾驶座的结果。走路的姿态：脚步沉，肩微塌 |
| 手指 | **重要视觉特征**：手指粗糙，指节粗大，有几处旧伤痕——钳工、焊工二十二年留下的印记。指甲短而整齐，边缘有洗不掉的油污印 |
| 妆造 | 无妆。不戴首饰。手腕上有戴了很多年的旧电子表的浅浅印痕 |
| 气质 | "一个人扛了二十二年，从没哭过"——沉默不是冷漠，是不知道怎么说。疲惫但不颓废：这个人还在撑着 |
| 年龄感 | 45岁，看起来比实际年龄老——常年体力劳动+离婚+跑夜车的叠加透支 |

## 半写实半水墨适配

> 风格分组：劳动者（赭石+焦墨，中度皴擦）

- **轮廓皴擦**：面部皱纹和颈部线条可用焦墨干笔皴擦，强调二十二年工厂留下的"磨损感"
- **手部特写**：手指关节和旧伤疤用焦墨提点——手是这个角色最诚实的叙事器官
- **光影**：车内暗蓝阅读灯（从上打下，冷暖对比），出租屋暗暖光（孤独的温暖）。两种光线都对半水墨友好——暗部可自然融入墨色晕染
- **眼泪**：场景2.11的泪痕——用留白+淡墨渲染，不要写实水珠的强反光（破坏水墨统一性）
- **手机屏幕光**：冷白光映在脸上——这是老周与外界唯一的情感通道，屏幕光和水墨暗部之间的过渡是核心视觉命题
- **禁止**：过度美化、强反光眼泪、"沧桑帅哥"化、英雄主义表情

## 核心符号

**手**——老周的手是全片最重要的视觉符号：
- 粗大的指节、旧伤疤——二十二年的体力劳动
- 握着方向盘时指节发白——压抑情绪
- 在手机屏幕上悬停、打字、删掉——犹豫
- 按下购买按钮——认了

**手机屏幕光映脸**——这是贯穿全片的"窗口"意象：屏幕里的温柔和屏幕外的孤独同时呈现在一张脸上。

### 关键视觉约束

- **年龄感要真实**：不是"帅大叔"，是一个被生活磨损过的45岁劳动者
- **手必须入戏**：所有车内镜头手上都要能看到粗大指节和旧伤
- **不夸张的眼泪**：落泪镜头是"无声流泪"不是"痛哭"，泪痕一条不是满脸
- **Polo衫是标志**：深蓝色、微松的领口——这是他在系统里唯一的"工作服"
- **不笑**：这个人不是不想笑，是很久没笑了
