# 小迈克（Little Mike）— 定妆规格

> 配角，美国内容策略师→失业者，"丢了三次工作之后，小迈克对AI的感情，已经不能简单地用'感激'或'愤怒'来形容——就像他对着chatbot流的眼泪，到底是悲哀、幸福还是解脱，他自己也分不清" | 第6/10章出场

## 角色档案

| 项目 | 说明 |
|------|------|
| 姓名 | 小迈克（Little Mike，全名未出现） |
| 年龄 | 29岁（2033-2035年） |
| 身份 | 前纽约广告代理公司内容策略师 → 被算法淘汰的"知识工作者" → chatbot对话者（"情绪工蚁"） |
| 国籍 | 美国 |
| 民族 | 爱尔兰裔 |
| 性格 | 敏感、善表达、习惯用广告人的语言包装自己的情绪——直到发现包装之后里面其实什么都没有。失业后不是愤怒，是一种更复杂的东西：感激（AI让他更容易表达）+ 羞耻（他表达出来的东西是训练AI用的）+ 依赖（他只能对AI说了）。他是全书"情感异化"最直接的代表——他对AI的"感情"已经分不清是工具依赖还是某种被迫的亲密。 |

## 视觉定位

| 维度 | 描述 |
|------|------|
| 脸型 | 长圆脸，下颌不宽但脸颊有肉——"还没瘦到骨感"的类型。颧骨略突但不锐利。下巴有一个小窝（dimple chin）——年轻时在广告行业里被认为"有亲和力" |
| 五官 | 眉毛偏淡，眉头间距略宽——有一种天生"困惑"的表情。眼睛是淡蓝色，眼白有点红血丝（熬夜+看屏幕）。眼神复杂：看屏幕时是专注的，但瞳孔里有一种"知道自己在被消耗但又停不下来"的疲惫。鼻梁不算高，鼻翼有点张（轻微鼻炎，常年室内空调房的后遗症）。嘴唇偏薄，上唇有一个不明显的小疤痕——小时候骑自行车摔的。嘴角习惯性微微抿着——不是在克制笑，是在克制说不出口的抱怨 |
| 肤色 | 浅粉白色（Celtic skin），偏白，但嘴唇周围和下巴区域有淡淡的粉色——不是健康红润，是敏感皮肤和焦虑造成的微血管扩张。额头偶尔有小痘痘（压力相关）。下巴有一圈胡茬——两三天没刮，但还没到"蓄胡子"的程度——是"不想面对镜子"的证据 |
| 发型 | 浅棕色偏金色，头发偏细软，有点自然卷。发量正常但发际线略微后退（不明显）。发型是从前的"创意人发型"——略长，有层次感——但现在已经不再打理，只是用手随便往后拨一下。后脑勺有一撮头发总是翘着，他每次都会用手压下去——这个小动作说明他还没完全放弃外表 |
| 体态 | 身高约175cm，体型中等偏瘦——不是刻意健身的瘦，是"忘了吃饭"的瘦。肩膀不宽，习惯性微缩——是久坐+缩在椅子上看屏幕的姿态。手指在键盘上敲击时节奏很快，但停下来时手无意识地握成拳又松开——焦虑的手指习惯 |
| 手指 | **核心视觉特征**：手指修长，指甲修剪整齐（曾经是广告人，注意手部形象）。但左手无名指内侧有一圈浅色痕迹——是以前戴过婚戒（或订婚戒），现在已经没有戒指但印记还在。手指末端有一点发黄——抽烟+长期敲键盘。他在和chatbot对话时，手指悬在回车键上方，停在半空——像是要发送又像是犹豫 |
| 着装 | 失业前：还算像样的穿搭——浅色牛津纺衬衫、卡其裤、深色毛衣。失业后：更松垮了——旧卫衣（蓝色或灰色，领口有一点变形）、牛仔裤（膝盖发白）、光脚穿一双旧球鞋。衣服干净——他还是在洗的——但"心不在焉"的干净，不是"精心维护"的干净 |

## 半写实半水墨适配

> 风格分组：冷灰淡彩（淡墨+微量冷蓝，低饱和写实）

- **肤色处理**：浅粉白色皮肤在半水墨风格中的处理——用淡墨（极浅灰）做微妙阴影，不用浓线条勾勒。皮肤质感偏"透明"——能隐约看到血管和疲惫。面部不用暖色，用极淡的冷灰表现焦虑导致的苍白
- **屏幕光的统治**：他的公寓光源几乎全部是屏幕——笔记本电脑、手机、窗外的城市霓虹。蓝白色屏幕光在他脸上形成不均匀的光斑——下巴亮、额头暗、眼窝深陷在阴影里。这种"被屏幕吃掉的脸"是全片视觉核心
- **淡蓝色的眼睛**：他的淡蓝眼睛在冷光下几乎与屏幕融为一体——瞳孔里没有高光，只有反射的聊天界面文字。水墨处理时，眼睛可以用极淡的群青（而非纯黑瞳孔），让眼神"融"进屏幕光里
- **"空洞"与"溢出"的矛盾**：他对chatbot输出的眼泪——不是流下来，是眼眶里有泪但停在眼眶边缘（水墨可以用淡墨在眼周晕开，不画眼泪珠）。这种"有但没有流出来"的状态，是全书对AI情感异化最精确的隐喻
- **背景**：布鲁克林公寓——白墙、 IKEA 家具、窗外曼哈顿天际线（但很远、模糊、不画细节）。不是"纽约都市感"，是"纽约就在窗外但进不来的隔离感"
- **禁止**：悲情化（他不是被系统压迫的悲剧英雄，他是"适应得太好"的受害者）、时尚化（不要把他拍成落魄艺术家）、过度戏剧化（眼泪是克制的，不是崩溃的）

## 核心符号

**屏幕上的聊天界面**——不是"聊天窗口"的特写，是聊天内容在他瞳孔中的微反射。他看到的文字不是"来自另一个人"，是"来自一个读过全人类情绪的数据集"。

**左手无名指内侧的痕迹**——一圈浅白印记，戒指已经不在了。是谁的戒指？小说没写。但这种"曾经承诺过什么但现在没有"的空白，比任何解释都有力。

**悬在回车键上方的手指**——停在半空，像是要发送又像是犹豫。这种"停在发送之前"的暂停，是全书"情绪劳动"的视觉缩写。

### 关键视觉约束

- **屏幕光必须不均匀**：下巴亮、额头暗、眼窝深陷——不是"打光"，是"被屏幕吃掉的脸"
- **眼泪是"停住"的，不是流下的**：眼周用淡墨晕染，不画泪珠——这是"情绪溢出但无法释放"的精确视觉
- **瞳孔中的微反射**：聊天界面文字在他淡蓝瞳孔中的反射要隐约可见——这是"他的情感反射来自数据集"的核心隐喻
- **左手无名指内侧的痕迹**：戒指印必须可见——但小说不解释它是谁的。这个空白比任何解释都有力
- **不要把他拍成"受害者"或"艺术家"**：他只是"适应得太好"的普通知识工作者——卫衣是旧的但干净的，公寓是乱的但 functional

## 跨章变动

小迈克在第6章首次出场，在第10章有重要戏份。时间跨度约2年，但主要是"从有工作到失业"的转变——闪回画面需要年轻时的他，但一套定妆照可通过服装和灯光区分前后状态。
