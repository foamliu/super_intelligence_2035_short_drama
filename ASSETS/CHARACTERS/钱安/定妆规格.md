> 配角，独立记忆保存者，"被删除的东西，和当年被销毁的书一样——都在被抹掉的人的声音里" | 第21章出场

## 视觉定位

| 维度 | 描述 |
|------|------|
| 脸型 | 长方形脸，颧骨略宽，下巴方正。面颊偏瘦——不是吃不好，是常年伏案研究+忘记按时吃饭 |
| 五官 | 眉毛粗而不乱，眉头习惯性微蹙——不是生气，是专注。眼睛不大，单眼皮，眼白有点浑浊（长期盯着微缩胶片和屏幕）。看文件时的眼神非常锐利，看人时反而有点躲。鼻梁不高但直。嘴唇偏薄，很少笑 |
| 肤色 | 偏白（室内为主），但脸和脖子有色差——脸白是因为在室内看档案，脖子和胳膊黑一点 |
| 发型 | 黑色短发，略显凌乱。鬓角几根白发。从不打理——早上起床毛巾擦一把脸就算梳过头 |
| 体态 | 身高约172cm，体型偏瘦。肩膀略斜——常年背单肩包（装硬盘和复印档案）。走路时微微低头，视线不在人上——在地面上、在路过的书架上、在别人手里的手机上 |
| 手指 | **核心视觉特征**：手指极细长，像用来翻页而不是握拳的。指甲较短但很干净。右手中指侧面有老茧——是笔。左手拇指和食指之间有经常摩挲纸角留下的薄茧——是档案 |
| 着装 | 深色便装（深灰/黑户外夹克、旧牛仔裤、深色衬衫），尽量不引人注意。口袋里永远装着U盘和一个折叠档案袋。不戴手表——"档案上的时间比手腕上的重要" |

## 半写实半水墨适配

> 风格分组：暖色学者（赭石+藤黄，中度晕染）

- **纸的质感**：钱安画面的视觉核心不是他的脸，是纸——档案纸、复印纸、发黄的纸、卷边的纸。水墨处理时，纸的质感比面部写实更重要——纸的纤维、霉斑、被揉过的折痕
- **光**：他常在暗处——档案室微弱的荧光灯、台灯下、电脑屏幕前。影子比光线多，暗部用水墨皴擦填充
- **手指**：翻档案的手指是核心符号——纤细、敏感、轻柔地触碰纸面。A4纸边缘的锋利与他手指的柔和形成视觉对比
- **留白**：他在档案堆里被包围，但面部留出空白——他不属于这些档案，他是这些档案的守护者。留白是"他在里面，也在外面"
- **禁止**：侦探化/特工化、阴郁化、过度戏剧化

## 核心符号

**纸**——发黄的档案纸、新打印的复印件、被揉过又展开的便签。纸是他与世界唯一的介质。

**手指上的茧**——中指侧是笔，拇指侧是纸。两枚茧是对称的，像一对括号括住了他的二十年。

**背包里的硬盘**——从不离身。那不是设备，是容器——装着他从无数被清空的服务器、被格式化的硬盘里抢救回来的记忆。

### 关键视觉约束

- **档案的质感比人脸锐**：档案架的金属锈迹、纸上的霉斑和水渍要写实——这是"正在消失"的证据
- **眼睛不要在镜片上**：眼镜反光要占镜片的一小部分，大部分眼睛是可见的，不能是纯白光
- **暗光不是阴暗**：暗部用墨色而不是灰色——半水墨的自然处理方式
- **手指是关键**：右手中指侧的老茧在握手/拿文件时可见——那是二十年笔耕的印记
