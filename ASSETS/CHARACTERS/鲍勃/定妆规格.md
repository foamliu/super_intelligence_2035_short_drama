# 鲍勃·韦伯 — 定妆规格

> 主角（第21集《美国梦的味道》），"他坐在窗前，不说话。他去工厂上班穿了二十多年同一件工装。" | 第21章出场

## 角色档案

| 项目 | 说明 |
|------|------|
| 姓名 | 鲍勃·韦伯（Bob Webb） |
| 年龄 | 22→66岁（1962-2002年去世） |
| 身份 | 汽车厂工人（22-50岁）→ 失业者（50-66岁） |
| 国籍 | 美国 |
| 民族 | 盎格鲁-撒克逊白人（WASP工薪阶层） |
| 性格 | 相信工会、相信制度、相信"工人是工人"。他的人生建立在"规矩保护人，制度运转，明天还在"的信念上。当工厂搬走、养老金蒸发、儿子说不进工厂时，这块石头松动了。最后几年坐在窗前不说话。他不是不想说话，是"想不清楚该信什么"所以不说话。 |

## 视觉定位（基础特征，跨年龄段不变）

| 维度 | 描述 |
|------|------|
| 脸型 | 方脸，下颌宽而方正。颧骨不突，面颊有肉——"能干活"的脸型。年轻时脸色红润，老了以后血色退掉，变成灰白色 |
| 五官 | 眉毛粗而浓，眉头习惯性微皱——不是生气，是"专注干活"的表情。眼睛是浅蓝色（比多萝西的更浅），年轻时眼神有力，老了以后眼神"空"——不是痴呆，是信仰崩塌后的空洞。鼻梁直但不高，鼻头略大（小时候打架留下的轻微偏斜）。嘴唇偏厚，嘴角自然下垂。笑起来有皱纹但不是笑纹，是"户外工作"晒出来的 |
| 肤色 | 浅粉白色，年轻时因为户外工作晒得偏红（不是健康红，是风吹日晒的红）。老了以后肤色灰白——不是病，是"不出去见太阳了" |
| 发型 | 深棕色短发，剪得很短（工厂安全规定）。发际线从30岁后开始后退，但不像多萝西那样明显——他的头发一直是短的，后退了也不太看得出来。40岁后开始掺灰，50岁后灰白参半，60岁后几乎全白但不稀疏 |
| 体态 | 身高约178cm。年轻时体格壮实——不是健身出来的肌肉，是"扛了二十年零件"的肌肉。肩膀宽，背直。50岁失业后肌肉开始流失，肚子开始出来（久坐+喝啤酒）。66岁时背微驼，肩膀缩了一点 |
| 手指 | **核心视觉特征**：手指粗而短，手掌宽厚——是工人的手。指关节因常年拧螺丝、搬零件而粗大。手掌内侧有老茧——不是一层，是很多层叠在一起。指甲永远有洗不掉的油污——即使洗澡后，指甲缝里还有淡淡的黑色。右手食指有一个旧疤——年轻时被零件划的 |

## 核心道具：工装

> 这件工装是全片最重要的道具之一，它的位置变化就是鲍勃人生的缩影：

- **1962-1988**：挂在厨房门后的固定钩子上——"工厂在家里的延伸"
- **1988年后**：从钩子上取下来，堆在"不要的"堆里
- **2002年多萝西搬家**：多萝西犹豫，拿起来，叠好，放进纸箱。纸箱上写"鲍勃的东西"。后来放在女儿家储藏室，再没打开过

工装的状态变化：
- 1962：新的，蓝色鲜艳，有油污但可以洗掉
- 1970s：布料旧了，颜色褪了，肘部有补丁
- 1980s：更旧了，油污洗不掉了，扣子掉了一个换成不一样的
- 1988后：不再穿，叠好放着

## 半写实半水墨适配

> 风格分组：从暖到冷的渐变（与多萝西同步但更有"金属感"）

- **22岁（1962）**：Kodachrome暖色调——但比多萝西更"硬"。他的皮肤有户外工作的粗糙感，用干皴笔触表现。淡赭+土黄为底色
- **45岁（1980s）**：暖色中渗入灰调——但他的灰调来自"动摇"而非环境的改变。眼神开始"空"——用淡墨在眼窝处晕染
- **50岁（1988）**：灰调主导——工厂关门后，他的脸色灰白。不是病，是"不出去见太阳了"。水墨的焦墨用于法令纹和眉间纹
- **66岁（2002）**：冷灰调——坐在窗前的背影。几乎不画正面——他最后几年的正面太"空"了。背影更有力：旧羊毛开衫，背微驼，肩膀缩，看着窗外空荡的街道
- **禁止**：蓝领英雄化（他不是《愤怒的葡萄》式的英雄，是普通工人）、悲情化（他的沉默不是悲剧，是"想不清楚"的停滞）、过度戏剧化（不要画他流泪或呐喊——他的崩溃是安静的）

## 核心符号

**工装**——穿了二十多年的蓝色工装。从门后钩子到"不要的"堆到纸箱。它的位置变化就是鲍勃的人生轨迹。

**"我是4073号"**——第一次见面时他报的是编号不是名字。这个细节说明他的自我认同是建立在"工厂系统"上的。当系统消失，他不知道自己是几号了。

**坐在窗前的背影**——最后两年，他坐在窗前，不说话。窗外是冬天空荡的街道。多萝西问"你在想什么"，他说"我是不是做错了什么"。这个背影是全片最安静的悲剧。

**手**——22岁时拧螺丝的手，45岁时攥着选票的手，50岁时垂在身侧的手。同一双手，从有力到无力。

### 关键视觉约束

- **22岁时不是"酷"的**：不是詹姆斯·迪恩式的叛逆青年，是"报编号而不是名字"的普通工人——笨拙但真诚
- **45岁的动摇不是"觉醒"**：他不是突然明白了什么——他是"想不清楚该信什么"所以选了一个说"不需要工会"的人
- **66岁的空不是"痴呆"**：是信仰崩塌后的空洞——他的整个自我认同建立在"工人是工人"上，当这个根基消失，他不知道自己是几号了
- **工装的位置变化**：门后钩子→"不要的"堆→纸箱——这三个位置必须在画面中精确呈现
- **不说活不是"拒绝沟通"**：是"想不清楚该说什么"——他的沉默里有内容，只是说不出来
