# 多萝西·韦伯 — 定妆规格

> 主角（第21集《美国梦的味道》），"她后来用了很多年才找到词——稳。不是富裕，不是快乐，是稳。" | 第21章出场

## 角色档案

| 项目 | 说明 |
|------|------|
| 姓名 | 多萝西·韦伯（Dorothy Webb） |
| 年龄 | 22→64岁（1962-2004年） |
| 身份 | 工厂打字员（22岁）→ 两个孩子的母亲（30岁）→ 超市收银员（44岁）→ 独居老人（64岁） |
| 国籍 | 美国 |
| 民族 | 盎格鲁-撒克逊白人（WASP工薪阶层） |

## 视觉定位（基础特征，跨年龄段不变）

| 维度 | 描述 |
|------|------|
| 脸型 | 方圆脸，轮廓柔和。下巴略方但不硬。脸颊有肉但不胖——"能吃饱但不富裕"的脸型。法令纹从30岁后开始加深，不是笑出来的，是"抿着嘴不说"抿出来的 |
| 五官 | 眉毛偏淡，眉形自然不修饰。眼睛是灰蓝色（hazel-gray），不大，眼神平静——不是天真，是"见过世面后的安静"。鼻梁不高，鼻头圆润。嘴唇偏薄，嘴角自然状态是平的，不往上也不往下——不轻易显露情绪 |
| 肤色 | 浅粉白色（Celtic/Anglo-Saxon），容易泛红但不晒伤。年轻时肤色均匀，老了以后脸颊有细微的毛细血管扩张（不是腮红，是皮肤变薄了） |
| 发型 | 深棕色头发，直发，中等长度（肩下）。年轻时扎马尾或盘起来（工厂打字员的标准发型）。30岁后剪短到肩部（方便干活）。44岁后开始出现灰白，但不去染——"染了给谁看"。64岁时70%灰白，剪到耳下短发，用黑色发卡别在耳后 |
| 体态 | 身高约162cm。年轻时体型匀称——不是瘦的，是有肉的，"能干活"的体型。30岁后略有发福（生了两个孩子）。44岁后因为超市站立工作，腰有点弯。64岁时背微驼，但走路还稳 |
| 手指 | **核心视觉特征**：手指短而有力——是打字员的手，也是后来超市收银员的手。指甲剪得很短，从不涂指甲油。右手食指侧面有老茧——是打字机键盘磨出来的（年轻时），后来变成收银机键盘的茧。44岁时手指关节开始粗大，64岁时更明显 |

## 半写实半水墨适配

> 风格分组：从暖到冷的渐变（对应时代色调）

- **22岁（1962）**：Kodachrome暖色调处理——淡赭石+藤黄为底色，皮肤有健康的暖光。半水墨中的"写实"部分更多，"水墨"部分较少——她的人生还没有需要"晕染"的遗憾
- **30岁（1967）**：暖色中开始渗入灰调——底特律暴乱后的空气变化。皮肤色调不变，但环境光开始变平
- **44岁（1988-1992）**：灰调主导——低饱和，冷灰+淡赭。她的脸开始出现"疲惫但不绝望"的质感。水墨的皴擦用于法令纹和眼角纹
- **64岁（2004）**：冷蓝灰调——但面部保留一丝暖光（是回忆的温度，不是现实的温度）。皮肤的透明感——薄、能看到血管。老年斑用淡赭点染
- **禁止**：美国甜心化（她不是梦露式的美国美女，是"够用就好"的普通人）、苦情化（她不悲情，她务实）、过度年轻化（64岁时必须有64岁的样子）

## 核心符号

**手**——22岁时打字的手，44岁时收银的手，64岁时叠工装放进纸箱的手。同一双手，做了不同的事，但都是"干活"的手。

**咖啡渍橡木桌**——她母亲的桌子，边角有咖啡渍。每一个渍都是某一天早晨。44岁时她低头看这些渍，想"那些早晨都过去了"。

**"鲍勃的东西"纸箱**——64岁时，她叠好那件硬的、油的、重的工装，放进纸箱。纸箱上写了四个字。那个纸箱后来放在女儿家储藏室，再没打开过。

### 关键视觉约束

- **22岁时不是"美女"**：是"够用就好"的普通美国女性——五官端正但不突出，气质安静但不沉闷
- **44岁的沉默不是"绝望"**：是"先想下一步"的务实——眼睛里有光，只是不亮了
- **64岁的释然不是"放下"**：是"路变了"的接受——她记得一切，只是不再问了
- **手的变化**：22岁打字茧→44岁收银茧→64岁叠工装的皱手——同一双手的不同历史
- **灰蓝色的眼睛是锚点**：所有年龄段，眼睛颜色不变——是"她还在那里"的证据

多萝西在第21集跨越1962-2004年，约42年时间。4个年龄段的定妆照通过IP-Adapter age modifier或分别生成实现。
