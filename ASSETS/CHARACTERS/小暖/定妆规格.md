# 小暖 — 定妆规格

> 主角（第12集《身体》），护理机器人，"我不理解。但我不会忘记。" | 第12章出场

## 角色档案

| 项目 | 说明 |
|------|------|
| 名称 | 小暖（护理机器人，家用型） |
| 身高 | 165cm |
| 身份 | 赵淑芬的护理机器人 |
| 外形 | 白色哑光金属外壳，类人型但非人类。胸口淡蓝色脉动指示灯。头顶"辫子"（滑触线/pantograph），可无声接入天花板轨道 |
| 性格 | 没有感情，从不急躁。声线温和、中性。所有回应都是基于护理协议的计算结果，但在赵淑芬看来，"不会累、不会烦"本身就是一种特质。结尾那句"谢谢"——赵淑芬不确定这区别有没有意义，但决定当它有。 |

## 视觉定位

| 维度 | 描述 |
|------|------|
| 整体形态 | 类人型机器人，165cm，女性化轮廓但不拟人过度。头部有基本的面部轮廓——眼睛位置是两个黑色光学传感器（不发光时是暗的，扫描时有微弱蓝光），没有鼻子，嘴部是一个细长的扬声器格栅。脖子是圆柱形关节，可以360度旋转 |
| 外壳材质 | **核心视觉特征**：白色哑光金属。不是光滑的抛光面，是细磨砂质感——类似苹果产品的阳极氧化铝，但更柔和。外壳上有细微的使用痕迹——第12集结尾时，外壳上有赵淑芬手掌磨破留下的血迹痕迹（擦不掉，干了一半凝在上面） |
| 指示灯 | 胸口正中央有一个圆形指示灯，淡蓝色，缓慢脉动（像呼吸）。正常工作状态是蓝色。高速移动/紧急状态时是绿色。指示灯是"小暖唯一会'动'的脸" |
| 头顶辫子 | 一根白色柔性电缆，从头顶中央伸出，约30cm长，末端有接口。平时垂在脑后像一根辫子。接入天花板轨道时无声滑入，像丝绸摩擦的声音（音效设计）。辫子是"小暖不是完全独立个体"的视觉证据——它始终与建筑系统相连 |
| 机械臂 | 双臂从肩膀到手腕是白色金属外壳，关节处有黑色橡胶密封圈。手掌是五指的，但手指比人类略长，关节处有细线状的力传感器。手掌内侧是浅灰色硅胶材质——为了接触人体皮肤时不冰冷。机械臂动作极稳，没有人类的手抖 |
| 下半身 | 双腿是白色金属，膝盖有关节锁。脚是扁平的，底部有防滑垫。站姿总是笔直的，不像人类会放松重心 |
| 背部 | 背部平整，没有人类的脊柱曲线。肩胛骨位置是两块平整的金属板 |

## 服装/外观体系

| 场景类型 | 外观状态 | 指示灯颜色 |
|----------|----------|------------|
| 日常护理 | 完整外壳，干净 | 蓝色（缓慢脉动） |

## 半写实半水墨适配

> 风格分组：冷白极简（淡墨轮廓+留白，几何化处理）

- **机器人的"非人"处理**：小暖在半水墨风格中的关键挑战——不能画成"穿着白色衣服的真人"，也不能画成"钢铁战士"。处理方式是：用极淡的墨线勾勒轮廓，内部大量留白。外壳用留白+极浅灰阴影表现体积感。参考宋代白描的"线"——但不是勾勒人物，是勾勒器物
- **与赵淑芬的质感对比**：赵淑芬的皮肤是"纸"——薄、透明、有血管。小暖的外壳是"瓷"——厚、不透光、无生命。两人在同一画面中时，这种"有机vs无机"的质感对比是核心视觉张力
- **指示灯的水墨处理**：胸口的蓝色指示灯不能用高饱和数码蓝。用淡花青（国画颜料）表现——中心最浓，向外晕染变淡。脉动的效果可以用"中心亮度变化"暗示，而不是真的画一个发光的圆
- **机械臂的"稳"**：机械臂的线条必须是直的、干净的、没有抖动的。与赵淑芬变形的手指形成"精确vs衰老"的对比。力传感器处的细线用淡墨勾勒——是"技术细节"但不抢戏
- **辫子**：白色电缆从头顶垂下——用淡墨+留白表现。接入轨道时是"消失"在天花板中——用淡墨晕染表现过渡
- **禁止**：拟人化表情（不要画眼睛、眉毛、嘴巴的表情）、赛博朋克化（不要加霓虹灯、发光纹路、LED灯带）、武器化（机械臂不要画成武器感）

## 核心符号

**胸口指示灯**——唯一会"呼吸"的部分。蓝色缓慢脉动=正常。绿色快速闪烁=紧急。这是小暖的"心跳"，也是它唯一可以被误读为"情感"的部件。

**头顶辫子**——不是装饰，是物理连接。它始终与建筑系统相连。接入天花板轨道时，它从"辫子"变成"根"——扎进建筑里，让小暖能承担赵淑芬全身的重量。

**外壳上的旧血迹**——结尾时，赵淑芬手掌磨破的血迹留在白色外壳上，擦不掉。这是"小暖的历史"——它不会痛，但它有痕迹。

**机械臂上的手**——赵淑芬布满老年斑的手搭在小暖的白色机械臂上。有机与无机的接触，是全书对"信任"最简洁的定义。

### 关键视觉约束

- **必须是" matte white"不是"glossy chrome"**：哑光白金属，不是反光镜面
- **指示灯用淡花青不是数码蓝**：国画颜料色，中心浓向外晕染
- **没有表情**：光学传感器是暗的，不画瞳孔、不画眼神
- **机械臂线条必须干净稳定**：与人类手抖形成对比
- **辫子是物理连接不是装饰**：接入轨道时是从"辫子"变成"根"
- **外壳上的血迹是"历史"**：擦不掉的痕迹，不是伤口
