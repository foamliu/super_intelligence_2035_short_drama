> 主角（第39集《空气》），前商场保安，"在商场他是'老李'，在培训中心是'那个学不会的'，在系统里是'47分'，但在王奶奶眼里——他是'小李'" | 第39章出场

## 视觉定位

| 维度 | 描述 |
|------|------|
| 脸型 | 圆方脸——下颌偏宽，咬肌有点发达（常年沉默时牙关紧咬的习惯）。脸颊肉不多不少——五十二岁还没开始消瘦，但也谈不上饱满。下巴有一道不明显的旧疤——很多年前撞在商场消防门上留下的 |
| 五官 | 眉毛粗但不浓，眉尾稀疏——年纪到了。眼睛偏小，单眼皮，眼白有点黄（常年上夜班）。眼神不凶，但"空"——不是空洞，是被掏空过又渐渐装回东西的"空"。看手机屏幕时微微眯眼——老花了但没去配眼镜。鼻头偏大，鼻梁有长期戴眼镜留下的浅浅压痕（但他现在不戴了——"反正也看不清楚"）。嘴唇偏厚，嘴角自然下垂，但偶尔一个瞬间——女儿打来视频时——唇角会不自知地松开 |
| 肤色 | 偏黄偏暗——一半是天生，一半是长期室内工作+熬夜攒下的。手背肤色比脸更深一些 |
| 发型 | 黑色短发，夹杂四五成灰白——不是全白，是"正在变白"。鬓角几乎全白。发际线后退，头顶发量稀疏。头发从未认真打理——早上起来水抹一把就算梳头 |
| 体态 | 身高约170cm左右。体型偏壮——保安制服下面是中年发福的肚子，但肩膀和胳膊还有干活二十多年攒下的肌肉棱角。站姿习惯性微躬——不是驼背，是习惯性"让一让"的身体记忆。走路时脚步偏重，不快 |
| 手指 | **核心视觉特征**：手指粗而短，指节因多年干活微微膨大。指甲短但甲缝有洗不掉的暗沉——是油、是灰、是五十年的生活留在指甲里的。右手食指肚有一个老茧——是手机。但这个茧下面还有更老的茧——是扳手、是推车把手、是二十年前修商场暖气管道时留下的 |
| 着装 | 日常：深色夹克（旧、洗过无数次、但干净）或灰蓝工装外套 + 深色长裤。手机永远放在外套内袋——贴胸口。裤兜里一包压扁的香烟，不一定抽，但一定在。脚上：深色运动鞋，鞋底磨偏了一边 |

## 半写实半水墨适配

> 风格分组：暖灰色调（焦墨+淡赭，中低饱和度）

- **灰度与墨色**：李师傅的底色是灰——不是黑、不是白，是"不多不少勉强过得去"的灰。灰调处理时使用焦墨的浓淡层次——不是纯灰色，是水墨的"五色墨"（焦、浓、重、淡、清），让灰有厚度
- **眼睛里的变化**：全片李师傅眼睛的关键变化——开始时"空"，接女儿视频时眼眶泛红（水墨可以用淡赭石晕一下眼周而不是画眼泪），最后看银杏叶时眼睛里有微弱的光。这个变化不是高光，是眼白里多了一点湿亮——最小面积的留白
- **手的老茧**：右手指的茧要用笔触强调——笔尖干皴，做出老茧粗糙的质感。茧不是"脏"，是"岁月"
- **手机屏幕**：全片最冷的光源——冷白色。与李师傅暖灰的皮肤形成对比。屏幕光在他脸上是冷的、硬的、不近人情的——但也是他和女儿之间唯一的通道
- **银杏叶**：第39集尾的唯一色彩——银杏叶的黄色（藤黄+淡赭）。在整集的灰调中，这抹金黄是第一个也是唯一"主动出现的颜色"。它不是系统给的，是自然落下的
- **禁止**：悲情化（他不是悲剧人物，他是正在走出来的人）、英雄化（他没有"战胜"系统，只是找到了自己的方式）、时尚化

## 核心符号

**手机**——屏幕上的"47分"是全书最克制也最残忍的字幕。手机在他宽厚的手里显得格外小，但这个小东西决定了他能不能贷款、能不能租房、能不能"存在"。

**老茧之下还有老茧**——右手食指肚：最上面一层是手机划出来的；下面是推车把手和扳手留下的。两层茧叠在一起，是他一生的剖面。

**银杏叶**——不是系统给他的认可，是王奶奶给他的称呼。不是分数，是"小李"。

### 关键视觉约束

- **眼睛必须是"空"的，不是"老"的**：他不是老态龙钟，是被系统掏空过后正在重新填满的状态——眼睛里有空间感，不是疲惫感
- **屏幕光是冷白色**：与环境暖灰形成视觉张力——系统是冷的，人是暖的
- **老茧不能美化或忽视**：右手食指肚的老茧在特写时必须清晰——粗粝的笔触处理
- **银杏叶的黄是全片唯一高饱和色**：黄不是金黄，是藤黄+淡赭——国画颜料色而非高饱和数码色
- **不要把他拍成"苦难"**：他不是被同情者，他是"正在走出来的人"
