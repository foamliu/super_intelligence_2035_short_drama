## 老李

### 角色档案

| 项目 | 说明 |
|------|------|
| 年龄 | ~65岁 |
| 身份 | 退休教师 |
| 出场 | 36集S21，数据权益联盟谈判桌 |
| 核心特征 | 知识分子的余热。他教书四十年，现在要用"讲道理"的方式争取权益。他的坐姿端正——是多年讲台训练。但他说话的语速慢——是老了，也是在斟酌措辞 |

### 视觉定位

| 维度 | 描述 |
|------|------|
| 脸型 | 长脸，瘦削。颧骨略突——是老了的骨感，不是营养不良 |
| 五官 | 眼睛温和但有神，是"见过太多学生"的眼神。鼻梁挺直，嘴唇薄，嘴角习惯性微微上扬——是多年微笑的职业习惯。老花镜挂在胸前，不是戴着——是"备用" |
| 肤色 | 偏黄偏暗（老年+室内）。皮肤松弛但干净——是"体面老人" |
| 发型 | 灰白短发，稀疏但整齐。发际线后退明显。头发梳向一侧——是旧习惯 |
| 体态 | 身高约170cm。体型偏瘦，背微驼但不严重。坐姿端正——双腿并拢，手放在桌上 |
| 着装 | 浅灰色中山装或旧式夹克（不是时尚选择，是"习惯了"）+ 深色长裤 + 黑布鞋。衣服洗得发白但干净。胸前口袋可能有钢笔 |

## 小王

### 角色档案

| 项目 | 说明 |
|------|------|
| 年龄 | ~28岁 |
| 身份 | 外卖骑手 |
| 出场 | 36集S21，数据权益联盟谈判桌 |
| 核心特征 | 体力劳动者的直接。他不习惯会议室，他的衣服是外卖制服，他的坐姿是"放松的警惕"。他是李明（外卖骑手，右腿截肢）的同行——但没有李明的悲剧。他代表"还没出事但随时可能出事"的大多数 |

### 视觉定位

| 维度 | 描述 |
|------|------|
| 脸型 | 方脸，宽下巴。面部轮廓硬朗——是风吹日晒的结果 |
| 五官 | 眼睛大但常眯着（户外工作习惯）。眉毛粗，鼻梁宽，嘴唇偏厚。表情直接——不懂"外交辞令"的警觉 |
| 肤色 | 偏黑偏粗糙（长期户外）。脸颊有红血丝（冬夏骑行）。皮肤有晒斑 |
| 发型 | 黑色短发，可能戴外卖头盔压出的痕迹。头发硬，有点乱 |
| 体态 | 身高约172cm。体型结实——不是健身房肌肉，是"每天爬楼"的结实。坐姿不端正——一条腿伸直，身体微侧 |
| 着装 | 外卖平台制服（蓝色或黄色，具体视平台而定）+ 运动裤 + 运动鞋。制服上有平台logo。膝盖处可能有磨损。手机随时在手边 |

| 项目 | 说明 |
|------|------|

| 出场 | 36集S21，数据权益联盟谈判桌 |

## 三人同框视觉构图

> S21 核心画面：谈判桌两侧。一侧是陈思危（技术创始人，深色高领毛衣，思维导图墙背景），另一侧是三个普通人——老李端正、小王警觉、小陈前倾。这是"技术精英 vs 草根代表"的构图

| 构图元素 | 处理 |
|----------|------|
| 视线高度 | 三人视线略低于陈思危（陈思危坐着但气场高） |
| 身体朝向 | 三人身体微侧向彼此——是"抱团"的姿态，不是各自为战 |
| 桌面道具 | 老李面前有保温杯，小王面前有手机，小陈面前有笔记本。陈思危面前什么都没有——只有他自己的双手 |
| 光线 | 会议室冷灰光。三人面部的光比陈思危稍暗——是"被照亮但不主导" |

## 半写实半水墨适配

> 风格分组：制度尝试（淡墨+花青，与36集法庭冷灰统一）

- **老李的"端正"**：坐姿、中山装、老花镜，用中锋线条——是旧秩序的残余。墨淡但笔正
- **小王的"直接"**：外卖制服、方脸、眯眼，用枯笔皴擦——是风风雨雨的痕迹。墨浓一点
- **小陈的"桥梁"**：前倾的姿态、圆珠笔、笔记本，用淡墨积染——是"中间地带"的柔和
- **三人同框**：用留白区分三人——不是挤在一起，是"三个独立个体临时结盟"
- **禁止**：悲情（他们不是受害者，是行动者）、整齐划一（三人气质必须明显区分）、热闹（谈判是克制的）
