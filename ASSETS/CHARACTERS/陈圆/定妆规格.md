# 陈圆 — 定妆规格

> 主角（林薇AI重建的历史人物），宋代茶坊老板娘，政和七年汴京，"三十二岁，有茶坊" | 第19章出场

## 视觉定位

| 维度 | 描述 |
|------|------|
| 脸型 | 偏方的小脸，下颌线条清晰但不刚硬。颧骨略高，脸颊有淡淡的红润——是灶火和蒸汽常年蒸出来的，不是胭脂 |
| 五官 | 眉毛偏粗但修得齐整，不弯不挑。眼睛不大，单眼皮，但目光很定——看人时不闪躲不媚笑，看茶汤时近乎虔诚。鼻梁直挺，嗅觉灵敏（茶评师的鼻子）。嘴唇偏薄，嘴角微微上翘——不是笑，是天生的弧度 |
| 肤色 | 偏白偏暖（室内为主），但手背和手腕肤色略深——常在炉灶边 |
| 发型 | 乌黑长发，束成宋代妇人常见的"包髻"——发髻盘在头顶略偏后，用素色布巾或木簪固定。几缕碎发散在鬓角和后颈。不戴珠翠 |
| 体态 | 身高约158cm左右，体型苗条但肩臂有力——揉面＋提水的年复一年。腰身窄，站姿端正——常年站在柜台后面的姿态 |
| 手指 | **核心视觉特征**：右手无名指微微弯曲——年轻时切菜伤过筋，后来好了但伸不直。手指细长但骨节分明，有几处烫伤的小疤。指甲短而干净，但甲缝边有一点洗不掉的面粉白 |
| 妆造 | 几乎无妆。最深的妆是嘴唇上一点茶汤的颜色。穿宋代民间常服：素色交领襦裙或窄袖短衣+长裙，颜色素净（月白、灰青、茶褐）。腰间系一条布带 |
| 气质 | "不是文人的茶，是劳动人民的茶"——她泡茶的时候手稳、眼定、不言语。那种气定神闲不是教养，是靠自己双手活下来以后的自然状态 |
| 年龄感 | 32岁，面容看起来正好32，不太年轻也不显老——是被烟火气浸润的熟龄 |

## 半写实半水墨适配

> 风格分组：历史人物（仿古宣纸底+墨线，重度水墨）

- **宣纸底**：背景整体偏暖黄旧色——仿宋代绢本的岁月感，但不做旧得过分（避免看起来像古画复制）。是"透过一层旧纸看一个人"的质感
- **墨线勾勒**：陈圆的轮廓线条比现代角色更明显——人物与背景的交界处可用细墨线勾勒，不是漫画勾线，是宋画线描的"铁线描"——细而有力
- **茶汤**：画面中唯一的高饱和色——茶汤的琥珀色。在整体低饱和的水墨调中，那一碗茶汤是唯一"活着的颜色"
- **蒸腾**：茶坊中永远有淡淡的水蒸气——用留白+淡墨渲染表现，不是写实烟雾
- **手指**：右手无名指的微曲要用特写强调——水墨的"笔断意连"在此处可表现为墨线到弯曲处略微断开，留一口气
- **建盏**：黑釉建盏是核心道具——黑色与茶汤琥珀色的对比是画面的视觉重心
- **禁止**：仕女图化、精致化、文人画化——她是劳动人民，不是画中仕女

## 核心符号

**右手无名指**——微曲的手指，年轻时切菜伤过筋。这是她"靠自己双手活下来"的视觉证明。

**茶汤**——琥珀色。是她唯一在意的东西。闻茶汤时的表情：闭眼，眉心微紧，嘴唇微动——是品评，是判断，也是一个女人的专注。

**建盏**——黑色的茶盏，粗粝但不笨。盛着琥珀色的茶汤。一盏在手，世界安静。

### 关键视觉约束

- **朝代正确是底线**：是宋（交领右衽、窄袖、包髻），不是唐（齐胸襦裙）不是明（立领）不是清（旗装）
- **无名指必须可见**：所有手部镜头都要验证右手无名指微曲
- **茶汤是调色盘上的唯一暖色**：画面中只有茶汤保持饱和琥珀色，其他一切低饱和
- **不要仕女图**：她是劳动者——衣服有褶皱、头发有碎发、手上有伤疤
- **时代锚点**：茶坊中的道具——建盏、木柜台、陶炉、石榴树——必须北宋民间风格
