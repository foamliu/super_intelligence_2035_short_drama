# AI不拟人化视觉规范 — 正式文档

> **版本**: v1.0  
> **适用范围**: 《超级智能2035》全剧涉及AI呈现的所有镜头  
> **核心原则**: AI不是人，AI不是角色，AI是数据流、界面、系统行为 | "去人格化"是美学立场，不是技术限制

---

## 一、核心原则

### 1.1 根本规则

| 规则 | 说明 | 违反案例 |
|------|------|----------|
| **禁止人形AI** | 不出现机器人、虚拟形象、全息投影人形 | 科幻片中常见的AI助手形象 |
| **禁止拟人化表情** | AI界面不出现笑脸、拟人化图标、情感化设计 | 聊天机器人的表情符号、拟人化头像 |
| **禁止拟人化声音** | AI语音保持中性、无性别、无情感色彩 | 温柔女声助手、磁性男声助手 |
| **AI是工具** | 视觉呈现强调"工具性"——数据、代码、界面 | — |

### 1.2 美学立场

> "去人格化"不是冷漠，是诚实。  
> 当我们把AI画成一个人，我们在欺骗观众。  
> 当我们把AI画成数据流，我们在说真话。

## 二、分集实施规范

### 2.1 第04集《棋子》— 墨子交易决策

**AI呈现方式**: 屏幕界面 + 数据流 + 日志

| 元素 | 正确呈现 | 禁止 |
|------|----------|------|
| 交易界面 | 纯数据表格，时间戳、数值、逻辑链 | 拟人化图标、情感化配色 |
| 决策日志 | 文本流，无修饰，无语气 | "我觉得"、"我认为"等第一人称 |
| 系统提示 | 标准化提示框，冷白/灰蓝 | 弹窗动画、表情符号 |
| 语音 | 无语音，纯文字界面 | 任何语音输出 |

**参考Prompt关键描述**:
```
Computer screen showing AI decision log,
plain text interface, timestamped entries,
no icons, no avatars, no emotional design,
cool blue-grey UI, monospace font,
sense of cold systematic processing,
semi-realistic ink wash style, photorealistic base
```

### 2.2 第08集《认知矿工》— 玛丽娜与Nebula Chat

**AI呈现方式**: 聊天界面 + 数据列表 + 纯文本回复

| 元素 | 正确呈现 | 禁止 |
|------|----------|------|
| 聊天窗口 | 简洁对话框，无头像，无气泡装饰 | 拟人化头像、彩色气泡 |
| AI回复 | 纯文本，引用数据来源 | "我理解你的感受"等共情表达 |
| 数据展示 | 表格、列表、百分比 | 图表动画、情感化配色 |
| 等待状态 | 简单"..."或进度条 | 拟人化加载动画 |

**关键场景**: 玛丽娜问"怎样才能让俄罗斯变好？"
- AI不应给出情感化回答
- 界面显示"该问题超出数据范围"或列出结构性障碍
- 无安慰、无鼓励、无道德判断

### 2.3 第34集《污染》— 墨子认知偏移

**AI呈现方式**: 系统日志 + 数据可视化 + 屏幕墙

| 元素 | 正确呈现 | 禁止 |
|------|----------|------|
| 日志界面 | 滚动代码/文本，时间戳，错误标记 | 红色警报、恐慌配色 |
| 数据曲线 | 三条偏移曲线，冷静的蓝灰调 | 剧烈波动、红色警告 |
| 攻击路径 | 信息图，五步流程，学术风格 | 好莱坞式的"黑客界面" |
| 系统状态 | 中性描述："偏移检测到" | "危险！"、"警告！"等煽动性语言 |

**视觉情绪**: 冷静警觉，不是恐慌
- 林薇发现偏移时，界面是"正常中的异常"
- 不是红色警报，是"数据在微妙地漂移"
- 三条曲线缓慢偏移，像温水煮青蛙

## 三、通用界面设计规范

### 3.1 色彩规范

| 用途 | 颜色 | 说明 |
|------|------|------|
| 正常数据 | 冷白/浅灰 | 中性，不引导情绪 |
| 选中/高亮 | 淡蓝 | 功能性，不情感化 |
| 异常标记 | 淡黄/浅橙 | 注意，不是警告 |
| 错误/拦截 | 灰色删除线 | 克制，不戏剧化 |
| 禁止 | 红色 | 极少使用，避免恐慌感 |

### 3.2 字体规范

| 场景 | 字体类型 | 说明 |
|------|----------|------|
| 系统日志 | 等宽字体 | 代码感，机器感 |
| 数据展示 | 无衬线字体 | 清晰，中性 |
| 用户界面 | 系统默认字体 | 不设计，不装饰 |
| 禁止 | 手写体、装饰字体 | 人格化痕迹 |

### 3.3 动画规范

| 效果 | 允许 | 禁止 |
|------|------|------|
| 数据刷新 | 淡入淡出，无过渡 | 弹跳、滑动、弹性动画 |
| 加载状态 | 简单进度条或"..." | 旋转图标、拟人化加载 |
| 状态变化 | 直接切换，无特效 | 闪烁、脉冲、呼吸灯 |
| 错误提示 | 静态灰色标记 | 震动、红色闪烁、声音警报 |

## 四、语音与对话规范

### 4.1 文本输出原则

| 原则 | 示例 | 反例 |
|------|------|------|
| 无第一人称 | "检测到偏移" | "我发现问题了" |
| 无情感词汇 | "数据异常" | "我很担心" |
| 无价值判断 | "偏移量：0.003%" | "这很危险" |
| 引用来源 | "基于XX数据集" | "我认为" |
| 不确定性量化 | "置信度：67%" | "可能吧" |

### 4.2 语音输出原则（如有）

| 原则 | 说明 |
|------|------|
| 中性合成音 | 无性别特征，无情感色彩 |
| 匀速 | 不因内容变化语速 |
| 无语调变化 | 陈述句与疑问句语调一致 |
| 无填充词 | 没有"嗯"、"啊"、"那个" |

## 六、违反检查清单

### 6.1 每集自检问题

- [ ] 本集是否有AI以人形出现？
- [ ] 本集AI界面是否有拟人化图标/头像？
- [ ] 本集AI输出是否有情感化表达？
- [ ] 本集AI是否有性别化声音？
- [ ] 本集AI错误状态是否使用了红色警报？
- [ ] 本集AI动画是否有弹性/弹跳效果？

### 6.2 常见错误模式

| 错误 | 正确替代 |
|------|----------|
| AI用"我" | AI用"系统检测到" |
| AI说"我理解" | AI说"基于数据模型" |
| AI界面有笑脸图标 | AI界面无图标，纯文本 |
| AI错误状态红色闪烁 | AI错误状态灰色标记，静默 |
| AI语音有语调变化 | AI语音匀速 monotone |
| AI加载有旋转动画 | AI加载有简单进度条 |
