# 半写实半水墨视觉规范 — 统一文档

> **版本**: v1.0  
> **适用范围**: 《超级智能2035》全剧25集 T2I/I2V 生成  
> **核心原则**: photorealistic base with Chinese ink wash aesthetic — 写实为骨，水墨为韵

---

## 一、核心风格定义

### 1.1 基准描述（所有Prompt必须包含）

```
semi-realistic ink wash style, photorealistic base with Chinese ink aesthetic
```

### 1.2 风格解读

| 维度 | "半写实"（photorealistic base） | "半水墨"（Chinese ink wash aesthetic） |
|------|-------------------------------|--------------------------------------|
| 造型 | 人物比例、结构符合真实人体 | 边缘可略有晕染，不追求摄影锐度 |
| 材质 | 皮肤、布料、金属有真实质感 | 质感用墨色层次替代部分光影 |
| 空间 | 透视准确，景深自然 | 远景可淡化处理，类似"留白" |
| 色彩 | 基础色调写实 | 整体偏灰、偏素，饱和度低于常态 |
| 线条 | 轮廓清晰 | 轮廓边缘可用枯笔、皴擦 |

## 二、水墨技法标准化词汇

### 2.1 必用技法词（按场景类型选择）

| 技法词 | 适用场景 | 效果说明 |
|--------|----------|----------|
| **淡墨** | 通用背景、阴影、远景 | 稀释的墨，层次丰富，不沉重 |
| **浓墨** | 暗部、轮廓、需要突出的结构 | 饱和的墨，压住画面重心 |
| **枯笔** | 纹理、皱纹、旧物、粗糙表面 | 干笔飞白，表现质感 |
| **留白** | 高光、光源、需要"空"的区域 | 不画即画，呼吸感 |
| **花青** | 冷调场景、科技空间、夜晚 | 偏蓝的冷灰，现代感 |
| **赭石** | 暖调场景、皮肤、木质、灯光 | 偏棕的暖灰，人情感 |
| **藤黄** | 阳光、灯火、暖金氛围 | 不饱和的黄，温暖但不刺眼 |
| **清水晕染** | 皮肤过渡、柔和边缘 | 墨与水自然融合，无硬边 |

### 2.2 技法组合公式

| 场景类型 | 公式 | 示例 |
|----------|------|------|
| 科技冷空间 | 淡墨 + 花青 + 枯笔 | 深智科技会议室/安全中心 |
| 暖调日常 | 淡墨 + 赭石 + 留白 | 社区服务中心/林薇直播间 |
| 夜景暖黄 | 赭石 + 藤黄 + 淡墨 | 路灯下/深圳露台 |
| 历史灰青 | 淡墨 + 花青 + 枯笔 | 明代织坊/空寂空间 |
| 历史暖金 | 赭石 + 藤黄 + 淡墨 | 宋代汴京/茶坊 |
| 历史暖褪 | 淡赭 + 枯笔 + 留白 | 底特律工厂/美国线 |
