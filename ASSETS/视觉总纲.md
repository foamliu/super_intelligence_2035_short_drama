# 视觉总纲 — 华夏AI漫剧

> 超级智能 2035 短剧视觉体系文档
> 更新时间：2026-07-22

---

## 一、总体定位

**视觉风格：半写实半水墨（Semi-Realistic Ink）**

融合两种美学基因：

| 基因 | 来源 | 关键词 |
|------|------|--------|
| 写实骨架 | 摄影/电影级 T2I 模型（Flux、Z-Image-Turbo 等） | 真实光影、物理材质、面部解剖准确 |
| 水墨魂 | 中国传统水墨画 + 宋代院体画 | 留白、意境、墨色层次、线描气韵 |

**一句话概括**：摄影机的真实 + 毛笔的呼吸。

## 二、核心视觉原则

### 2.1 人物

| 维度 | 标准 |
|------|------|
| 面部 | 解剖准确、骨骼肌肉写实（不接受卡通/二次元/美型过度） |
| 皮肤 | 自然肤质，可见毛孔和细微纹理，**拒绝塑料皮/AI脸** |
| 光影 | 自然漫射光为主（柔光箱/阴天窗光），硬光仅用于戏剧性场景 |
| 轮廓 | 人物与环境交界处允许 ≦2px 的微妙水墨晕染边缘（"笔断意连"） |
| 眼神 | 必须传达角色情绪，拒绝空洞/死鱼眼 |

### 2.2 环境

| 维度 | 标准 |
|------|------|
| 建筑 | 中式场景采用水墨渲染的远景层次，近景写实 |
| 自然 | 山水/天空借鉴宋画皴法与泼墨留白 |
| 科技 | 屏幕/数据流/HUD 采用简洁几何线条，色彩统一在低饱和冷色系 |
| 过渡 | 场景切换可插入纯水墨空镜（2-3秒）作为"呼吸" |

### 2.3 色彩体系

| 层级 | 配色 | 用途 |
|------|------|------|
| 基底 | 墨色（#1a1a1a - #4a4a4a 渐变） | 轮廓、阴影、远山 |
| 人物暖系 | 赭石、朱砂、藤黄 | 林薇、王建国、陈圆等暖色人物 |
| 人物冷系 | 花青、石青、钛白 | 陈思危、AI角色、国际人物 |
| 科技/AI | 深蓝 → 紫色渐变（不饱和） | 星云、数据流、屏幕界面 |
| 警示 | 朱砂红（仅用于关键叙事节点） | 危机/封印/法庭 |

### 2.4 比例与构图

| 维度 | 标准 |
|------|------|
| 画幅 | **16:9（1280×720）**，统一基准 |
| 景别 | 近景（角色情感）> 中景（动作/交互）> 远景（环境/意境） |
| 留白 | 中景构图至少保留 15-25% 留白区域（水墨传统） |
| 机位 | 写实风格：肩扛感、呼吸感、焦点游移；拒绝完美稳定 |

## 三、T2I 生成标准

### 3.1 通用 Prompt 模板

```
[角色描述],
[semi-realistic ink wash style],
cinematic lighting, natural diffused light,
shallow depth of field, realistic color grading,
subtle ink wash edges at figure-environment boundary,
[场景背景描述],
1280x720, 16:9 aspect ratio, photorealistic base with Chinese ink aesthetic
```

### 3.2 通用负面 Prompt

```
ugly, deformed, bad anatomy, disfigured, poorly drawn face,
mutation, extra limb, extra fingers, fused fingers,
blurry, watermark, text, logo, oversaturated,
plastic skin, heavy makeup, beauty filter,
anime, cartoon, illustration, 3D render, CGI look,
doll-like, dead eyes, vacant stare,
overexposed, HDR, neon, saturated colors,
Western oil painting, Baroque lighting
```

### 3.3 输出画幅

- 基准画幅：**1280×720（16:9）**
- IP-Adapter 参考图：同上画幅
- 竖向构图（少数情绪场景）：720×1280

## 四、人物风格分组

| 分组 | 人物 | 色调 | 水墨强度 |
|------|------|------|---------|
| 暖色学者 | 林薇、陈圆、袁子轩 | 赭石+藤黄 | 中度晕染 |
| 冷色决策者 | 陈思危、赵建军、王磊 | 花青+墨色 | 轻度线描 |
| 劳动者 | 王建国、老赵、老周、迈克、李思远 | 赭石+焦墨 | 中度皴擦 |
| AI 实体 | 墨子、星云、小暖、小华 | 深蓝紫+银白 | 纯几何/光效（无水墨） |
| 国际角色 | 普里亚、约翰内斯、卡洛斯、莉娜、奥蒂诺 | 各文化主色+墨色骨架 | 轻度晕染 |
| 历史人物 | 林薇祖父、陈圆（宋代） | 仿古宣纸底+墨线 | 重度水墨 |
| 少年 | 小迈克、袁子轩、小林、陈远 | 中明度暖调 | 中度留白 |

```
（表格：场景类型/服装/颜色）

## 半写实半水墨适配
（关键视觉约束，水墨化处理要点）

## 定妆照需求
（必拍清单表格）

## T2I Prompt 模板
（基准 Prompt + 负面 Prompt）
```

## 六、文件命名规范

```
ASSETS/CHARACTERS/[角色名]/定妆规格.md    # 必选
ASSETS/CHARACTERS/[角色名]/[编号]_[类型].png  # 生成图
```

编号规则：
- `01_正面定妆` — IP-Adapter 锁定
- `02_半侧面` — 对话/思考
- `03_场景` — 主场景中景
- `04_情绪特写` — 关键情感节点
- `05_手部/符号` — 角色核心符号特写（如有）
