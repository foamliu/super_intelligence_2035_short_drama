## 核心元素详述

### 1. 长会议桌（场景中心）

| 属性 | 描述 |
|------|------|
| 材质 | 浅灰色人造石或哑光金属，无木纹。表面干净但有使用痕迹（轻微划痕、杯印） |
| 尺寸 | 约400×120cm，容纳12-14人 |
| 桌面物品 | 矿泉水瓶（农夫山泉或怡宝，中国品牌）、A4纸文件、黑色签字笔、笔记本电脑（合上或打开）、手机（屏幕朝下）。36集数据信托谈判时，桌上多了"数据权益联盟"的简陋资料 |
| 椅子 | 黑色网面人体工学椅，有滚轮。不是皮椅，是"科技公司"的实用选择 |

### 2. 白板（思想交锋的战场）

| 属性 | 描述 |
|------|------|
| 尺寸 | 约200×100cm，壁挂式 |
| 内容 | 25集：陈思危写"透明度哲学"，赵建军的对侧是"主权逻辑"。字迹是各自的手写体——陈的字偏草，赵的字偏正 |
| 笔迹 | 黑色马克笔，有擦除痕迹（之前的内容没擦干净）。白板边缘有笔槽，里面躺着3-4支不同颜色的笔（黑、红、蓝），有的没盖盖子 |
| 36集变化 | 数据信托谈判时，白板上有流程图和关键词，用多种颜色区分 |

### 3. 照明系统

| 光源 | 色温 | 强度 | 说明 |
|------|------|------|------|
| 顶灯 | 5000K | 主光源 | 嵌入式LED面板灯，均匀分布，无阴影。典型的写字楼照明 |
| 窗户自然光 | 变化 | 辅光源 | 深圳阴天/傍晚时，灰蒙蒙的光从百叶窗漏进来 |
| 屏幕/投影 | 6500K | 局部 | 偶尔使用，不是每一场都有 |

**光影特征**：
- 顶灯均匀，人物面部无明显阴影——这是"制度空间"的特征，不是戏剧性照明
- 窗户方向的面部略亮，另一侧略暗——形成微妙的明暗对比
- 整体：冷白为主，灰为辅，无暖色

### 4. 窗户与窗外

| 属性 | 描述 |
|------|------|
| 结构 | 落地窗，双层玻璃，百叶窗半拉 |
| 窗外 | 深圳城市景观。不是海景豪宅视野，是"写字楼中层"的普通景观——其他写字楼、道路、绿化。阴天时灰蒙蒙，傍晚时有隐约的城市灯光 |
| 天气 | 25集多为阴天或傍晚（要下雨）。36集数据信托谈判时可能是白天 |

### 5. 墙面与装饰

| 属性 | 描述 |
|------|------|
| 墙面 | 白色乳胶漆，干净但无质感。有一面墙是玻璃（隔断其他办公区），玻璃上有深智科技的logo（简约字体，不显眼） |
| 装饰 | 几乎无装饰。没有画，没有植物，没有励志标语。是"功能性空间" |
| 摄像头 | 角落有一个小型会议摄像头，红色指示灯偶尔亮起 |

### 6. 其他

| 元素 | 描述 |
|------|------|

## 半写实半水墨适配

> 风格分组：制度冷灰（淡墨+花青，清晰线条，大量留白）

- **空间的"制度感"**：不是豪华，是"标准"。用淡墨+花青表现空间的冷灰调，线条清晰笔直——桌子边、白板框、窗户框都是直线。没有曲线，没有装饰
- **长桌的对峙感**：桌子是画面的水平分割线。两侧人物形成视觉对峙。水墨处理时，桌面用清晰的淡墨线，人物用更浓的墨，形成"空间衬托人"的效果
- **白板的"思想痕迹"**：白板上的字迹是思想交锋的证据。用枯笔表现马克笔的质感，字迹边缘略模糊（没擦干净）。"透明度哲学"和"主权逻辑"的字迹风格要不同——陈的飘逸，赵的端正
- **窗户的灰蓝**：窗外深圳阴天，灰蓝调。用淡墨+花青，与室内冷白形成微妙的冷暖对比
- **玻璃的透明感**：玻璃隔断墙用极淡的墨+留白，暗示透明但存在。门外的人影用更淡的墨，形成"另一个世界"的感觉
- **禁止**：科幻感（不是未来空间）、豪华感（不是五星酒店会议室）、温暖感（不是咖啡馆）、混乱感（桌面整洁，文件整齐）
