# 林薇直播间/书房 — 背景规格

> 核心重复场景（22/24/25/34集），林薇的私人空间，"数据的声音"的发源地 | 与周沫出租屋直播间形成鲜明对比

---

## 场景定位

| 项目 | 说明 |
|------|------|
| 地点 | 上海某老旧小区，林薇租住的单间公寓 |
| 时间 | 2033-2035年，冬夜为主 |
| 功能 | 直播间 + 编辑台 + 书房 + 卧室（一室多用） |
| 核心特征 | 整洁但不精致，有书卷气但不文艺，实用但不简陋。是"一个认真生活的人"的空间，不是"一个展示生活的人"的空间 |

## 核心元素详述

### 1. 木质书桌（场景中心）

| 属性 | 描述 |
|------|------|
| 材质 | 老榆木或水曲柳，二手家具市场购入。桌面有使用痕迹（轻微划痕、茶杯印、墨迹），但不脏 |
| 尺寸 | 约120×60cm，高度75cm |
| 桌面物品 | 24寸显示器（居中）、机械键盘（黑色，无灯效）、有线鼠标、鼠标垫（纯色，无图案）、笔筒（装满笔和尺子）、几本摊开的书、A4纸（手写笔记）、手机支架（简单塑料款）、一个小盆栽（多肉，偶尔忘记浇水） |
| 台灯 | **核心光源**。老式银行台灯（绿色玻璃罩，黄铜底座，可调节角度）。灯泡是暖黄LED（2700K）。灯罩有轻微灰尘。电线从桌面后方垂下，用理线带 loosely 绑着 |
| 抽屉 | 半开状态可见：更多A4纸、充电器、胶带、回形针、一枚旧硬币（无用但没收起来） |

### 2. 书架（背景核心）

| 属性 | 描述 |
|------|------|
| 结构 | 宜家式简易书架（或二手木书架），约180×80cm，五层 |
| 书籍 | 满但不乱。历史类为主（宋史、明史、科技史），夹杂AI/机器学习入门书（她需要理解墨子的语言）。书不是摆拍的新书，是"真的读过"的——有折角、便利贴、批注 |
| 杂物 | 第三层有一个小盒子（装便签和回形针），第四层有一个旧收音机（不用但留着），最底层有几个文件夹 |
| 灰尘 | 书架顶部有轻微灰尘——她够不到，也不常擦 |

### 3. 白墙与便签

| 属性 | 描述 |
|------|------|
| 墙面 | 白色，但有岁月痕迹。左下角有之前租客留下的钉子孔（她用便利贴盖住）。右上角有一块淡黄色水渍（楼上漏水，已干） |
| 便签 | 少量，不超过5张。用蓝丁胶贴着。内容是待办事项或灵感（"陈圆地契日期核实""墨子输出异常？"），字迹是她的手写体 |

### 4. 窗户

| 属性 | 描述 |
|------|------|
| 结构 | 老式铝合金窗，双层玻璃（隔音差），窗框有锈迹 |
| 窗帘 | 浅灰色棉麻窗帘，半开状态。不遮光，透光 |
| 窗外 | 上海冬夜。对面楼的窗户灯光。偶尔有雨（24集核心）。没有霓虹灯，没有繁华夜景，是"普通小区"的夜景 |
| 窗玻璃 | 有轻微灰尘和雨痕（冬雨时）。室内暖气与室外冷温形成轻微雾气 |

### 5. 单人床

| 属性 | 描述 |
|------|------|
| 位置 | 靠墙，不常入镜 |
| 状态 | 整理干净。床单是素色（浅蓝或浅灰）。被子叠好或铺开（视时间而定）。枕头边有一本书（睡前阅读） |
| 床头柜 | 一个小凳子代替。上面是手机充电器和水杯 |

### 6. 其他

| 元素 | 描述 |
|------|------|
| 地板 | 老木地板，有磨损痕迹，颜色不均匀。一块小地毯（60×90cm）在书桌下方，防止椅子刮地板 |
| 椅子 | 人体工学椅（二手，调节杆坏了，固定在一个高度）。黑色网面，有使用痕迹 |
| 空气 | 冬天暖气+屏幕散热+台灯的混合温度。不闷热，是"长时间待着"的熟悉感 |

## 光照系统

| 光源 | 色温 | 强度 | 范围 | 说明 |
|------|------|------|------|------|
| 台灯 | 2700K | 主光源 | 桌面半径60cm | 核心氛围光，暖黄，有阴影 |
| 屏幕 | 6500K | 辅光源 | 面部/上身 | 冷白，随内容变化 |
| 窗外夜景 | 4000K | 背景光 | 窗户区域 | 城市灯光，冷调 |
| 房间吸顶灯 | 5000K | 关闭/极少 | 全屋 | 几乎不用，台灯足够 |

**光影特征**：
- 台灯从左侧（或右侧，固定一个方向）照来，形成清晰的明暗分界
- 屏幕光在面部形成冷白反光，与台灯暖黄形成对比
- 窗外夜景在窗户玻璃上形成反射，偶尔映出林薇的侧影
- 整体：暖黄为主，冷白点缀，黑暗为辅

## 色调与氛围

| 维度 | 描述 |
|------|------|
| 主色调 | 暖黄（台灯）+ 木色（书桌/书架）+ 白色（墙） |
| 辅色调 | 冷白（屏幕）+ 深灰（窗外夜景）+ 浅蓝（床单） |

| 气味（暗示） | 旧书、台灯灯泡的微热、窗外冬雨的空气、屏幕散热的电子味 |

## 半写实半水墨适配

> 风格分组：书房暖寂（淡墨+赭石，大量留白，清水渲染）

- **书桌的木质温暖**：老榆木的纹理用淡墨+赭石表现，划痕和茶杯印用枯笔暗示。不是光滑的新木，是"用了多年"的温暖
- **书架的"知识重量"**：满架的书用淡墨层层推远，形成景深。书脊的颜色不画，用墨色深浅区分。书架本身的木框用清晰的线条，与模糊的书形成对比
- **台灯的暖黄核心**：台灯是画面的光心。用赭石+淡墨渲染光晕，边缘用清水破开，形成"光在黑暗中晕开"的效果。灯罩的绿色玻璃用极淡的花青暗示
- **窗外冬雨**：24集核心。窗户玻璃上的雨痕用枯笔快速扫过，窗外的夜景用淡墨+花青，形成"冷雨中的暖室"对比
- **白墙的留白**：墙面大面积留白，只用极淡的墨暗示岁月痕迹（钉子孔、水渍）。便签用淡墨+少量赭石，成为白墙上的微妙点缀
- **禁止**：网红书房（没有ins风摆件、没有香薰、没有咖啡杯摆拍）、阴暗压抑（不是地下室，是正常公寓）、过度整洁（她有真实的生活痕迹，但不是乱）

## 跨集变动

| 集次 | 场景状态 | 核心变化 |
|------|----------|----------|
| **22集《代价》** | 直播间讲述模式 | 桌上摊开三件史料（地契、册子、工牌）。台灯为主光源，氛围庄重。书架背景清晰 |
| **24集《止于数据》** | 编辑台挣扎模式 | 冬雨窗外。屏幕为主光源（关掉台灯时）。光标闪烁的空白文档。在线人数界面。更冷、更内心化 |
| **25集《工作组》** | 审阅日志模式 | 台灯+屏幕。墨子日志界面。手指悬停。警觉但不恐慌 |
| **34集《污染》** | 凌晨三点读日志 | 台灯调暗。屏幕冷白为主。窗外漆黑。最警觉、最孤独 |

## 与周沫出租屋的对比

| 维度 | 林薇直播间 | 周沫出租屋 |
|------|-----------|-----------|
| 整洁度 | 整洁，有秩序 | 凌乱，生存空间 |
| 光源 | 台灯+屏幕，暖黄为主 | 台灯+屏幕，但更简陋 |
| 墙面 | 白墙+少量便签 | 白墙贴满A4纸公式 |
| 书架 | 满架真书 | 无书架，书堆在角落 |
| 桌面 | 显示器+键盘+文具 | 手机支架+泡面盒+外卖袋 |
| 氛围 | 书卷气，思考的空间 | 生存感，坚持的空间 |
| 窗外 | 上海冬雨，普通小区 | 上海夏阳，老破小 |
