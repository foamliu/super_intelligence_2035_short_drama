# 第37集《丰裕》— 路边台阶夜景背景规格

> **核心视觉符号**：路灯下两个中年人的影子，比人脸更重要 | 缓慢、共同、继续  
> **与角色定妆的交互**：李师傅"怀疑但尝试" + 老张"被困但继续" = 影子里的尊严  
> **风格分组**：社区暖夜（淡墨+赭石+暖黄路灯，水墨夜景）

| 项目 | 说明 |
|------|------|

## 核心元素详述

### 1. 路灯（场景光源核心）

| 属性 | 描述 |
|------|------|
| 类型 | 老式高压钠灯或LED路灯，上海街头常见款 |
| 色温 | 2700K-3000K，暖黄色 |
| 亮度 | 照亮人物和周围2-3米，之外逐渐暗淡 |
| 光锥 | 有明显的光锥边界，飞蛾在光中飞舞（可选细节） |
| 灯杆 | 灰色金属杆，有城市编号/小广告贴纸痕迹 |

**光影特征**：
- 人物面部从下方被照亮（路灯在头顶），形成底光效果——不是恐怖，是"夜晚的真实"
- 手机屏幕的冷白微光补充面部细节
- 影子从人物脚下向远处拉长，影子边缘模糊（路灯不是点光源）

### 2. 人行道/马路牙子（座位）

| 属性 | 描述 |
|------|------|
| 形态 | 水泥马路牙子，高约15-20cm |
| 质感 | 粗糙，有裂缝，有落叶或烟头（不刻意清洁） |
| 位置 | 路灯正下方或略偏 |
| 周围 | 人行道地砖，老旧，有不规则的修补痕迹 |

### 3. 背景环境（暗夜层次）

| 层次 | 元素 | 亮度 | 说明 |
|------|------|------|------|
| 近景 | 马路牙子、人物、手机 | 暖黄主光+冷白补光 | 清晰 |
| 中景 | 人行道、树影、停放的电动车/自行车 | 暗，路灯边缘光 | 隐约可见 |
| 远景 | 老旧居民楼、便利店灯箱、窗户微光 | 极暗，点缀微光 | 氛围层 |

### 4. 手机屏幕（冷白微光）

| 属性 | 描述 |
|------|------|
| 亮度 | 照亮人脸下半部，形成冷暖对比 |
| 内容 | 培训APP界面，中文字，字偏大（老年人模式） |
| 动态 | 两人看同一部手机（老张教李师傅），或各自手机显示同一内容 |

## 半写实半水墨适配

> 风格分组：社区暖夜（淡墨+赭石+暖黄路灯）

- **路灯的"暖黄晕染"**：路灯不是清晰的灯泡，是"一团暖黄"的光晕。水墨处理时，光源用淡赭+藤黄，边缘用清水破开，形成自然的晕染。飞蛾在光中用小墨点表现
- **影子的"淡墨拉长"**：两个影子是核心视觉。影子用淡墨，边缘模糊，向远处逐渐变淡。影子不是黑色，是"路灯黄+地面灰"的混合——用赭石+淡墨。影子里不画细节，画轮廓
- **人物面部的"底光"**：从下方照亮的脸，上半部暗，下半部亮。水墨处理时，暗部用淡墨，亮部留白+微量赭石。手机屏幕的冷白用极淡的花青表现
- **背景的"暗部留白"**：远处的建筑、树木，用浓墨+大量留白（留黑）。只画轮廓，不画细节。便利店灯箱用极小的高光点
- **地面的"粗糙质感"**：水泥马路牙子、地砖裂缝。用枯笔+皴擦，表现城市的老旧质感。落叶用焦墨小点
- **禁止**：明亮的街景（不是商业区）、霓虹灯（不是赛博朋克）、空旷无人的孤独感（是两个人）、清晰锐利的影子（路灯影子是模糊的）

## 与角色定妆的交互约束

| 场景 | 角色 | 交互约束 |
|------|------|----------|
| 路灯下 | 李师傅+老张 | 李师傅的"怀疑但尝试" vs 老张的"被困但继续"——两种姿态在影子里融合 |
| 手机屏幕 | 老张手指+李师傅注视 | 老张手指粗大笨拙但稳定，李师傅认真但缓慢 |
| 影子 | 两人剪影 | 影子里不区分谁是谁，是"两个中年人"的共同体 |
| 远景 | 无 | 背景安静，没有行人打扰，是只属于两人的夜晚 |
