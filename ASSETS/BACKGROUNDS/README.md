## 背景规格标准结构

每份背景规格包含：

1. **场景 establishing shot** — 环境全景
2. **关键局部/细节** — 特写（如：地板纹理、墙面痕迹）
3. **光线氛围** — 时段与色调
4. **T2I Prompt 模板** — 可直接用于生成
5. **与角色定妆的交互约束** — 背景如何衬托角色
