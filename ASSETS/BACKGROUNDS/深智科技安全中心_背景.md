# 深智科技安全中心 — 背景规格

> 核心场景（34集《污染》），认知免疫系统分析空间 | 多块屏幕墙，冷蓝灰，数据可视化核心 | 与25集会议室区分：更技术、更数据、更警觉

---

## 场景定位

| 项目 | 说明 |
|------|------|
| 地点 | 深圳南山区，深智科技总部大楼，地下一层/低层安全运营中心（SOC） |
| 时间 | 2033年，凌晨/深夜为主（S01林薇书房→S06紧急召集） |
| 功能 | 安全监控、数据分析、威胁检测、应急响应 |
| 核心特征 | 不是会议室的"谈判"，是"作战室"。多块屏幕墙实时显示数据流，工作站呈弧形排列，键盘声与服务器风扇是环境音。冷蓝灰是主色调，比会议室更蓝、更冷。没有长桌，没有白板（或白板是辅助），屏幕是唯一的"墙面装饰" |

## 核心元素详述

### 1. 屏幕墙（场景绝对核心）

| 属性 | 描述 |
|------|------|
| 数量 | 3-4块主屏幕墙，每块由2×2或3×2的显示屏拼接而成 |
| 尺寸 | 单屏约55寸，拼接后每面墙约300×200cm |
| 内容 | **屏幕A**：数据源实时监控（六个月分布变化曲线）<br>**屏幕B**：推理链可视化（攻击路径五步图）<br>**屏幕C**：输出监控与指标漂移（三条平行曲线）<br>**屏幕D**（可选）：系统日志流（滚动代码） |
| 界面风格 | 冷蓝灰UI，深色背景，数据可视化优先。不是科幻全息，是真实的SOC界面。字体是等宽或系统默认，无装饰 |
| 亮度 | 屏幕是空间最亮的光源，照亮操作员的面部 |

### 2. 弧形工作站（操作区）

| 属性 | 描述 |
|------|------|
| 布局 | 弧形排列，面向屏幕墙。每个工位双显示器+键盘+鼠标 |
| 桌面 | 深灰色哑光金属，线缆整齐收纳（或故意裸露的工业感） |
| 椅子 | 黑色网面椅，比会议室更实用，有磨损痕迹 |
| 设备 | 机械键盘（声音）、降噪耳机（挂在显示器旁）、咖啡杯（有渍）、便签纸（手写） |
| 人员 | 安全工程师们，穿休闲或公司文化衫，不是正装 |

### 3. 中央分析台（决策区）

| 属性 | 描述 |
|------|------|
| 位置 | 工作站弧形的圆心，面向屏幕墙 |
| 形态 | 高脚桌或站立工作台，无椅子（或只有一张高脚凳） |
| 桌面 | 笔记本电脑、外接显示器、手写板、纸质笔记 |
| 使用 | 林薇站在这里召集紧急会议，三人围站分析。不是"坐谈"，是"站立作战" |
| 光线 | 屏幕光从三个方向打在脸上，形成多源冷光 |

### 4. 服务器/设备间（背景音源）

| 属性 | 描述 |
|------|------|
| 位置 | 角落，玻璃隔断门 |
| 可见 | 机架、闪烁的指示灯、线缆 |
| 声音 | 服务器风扇的低频白噪音，硬盘读写的细微声音 |
| 光线 | 门缝漏出的冷白LED光，地面有淡淡的蓝色反光 |

### 5. 照明系统

| 光源 | 色温 | 强度 | 说明 |
|------|------|------|------|
| 屏幕墙 | 6500K | 主光源 | 多块屏幕的复合光，照亮人脸和桌面 |
| 环境灯 | 4500K | 极低 | 天花板边缘的暗槽灯，仅提供基本导航亮度 |
| 设备间 | 6000K | 背景 | 服务器指示灯，闪烁，不稳定 |
| 应急灯 | 红色 | 备用 | 角落的消防指示灯，常年微亮 |

**光影特征**：
- 屏幕光是唯一有意义的光源，人物面部被冷蓝灰光照亮
- 多屏幕造成多方向光源，面部阴影复杂但不强烈
- 没有顶灯直射（或顶灯极暗），空间大部分在阴影中
- 键盘和鼠标有微弱的RGB背光（可选），增添技术感

### 6. 墙面与地面

| 属性 | 描述 |
|------|------|
| 墙面 | 深灰色或黑色吸音板，不是白色。用于减少服务器和键盘的噪音反射 |
| 地面 | 防静电地板，深灰色，有网格纹理。地板下有线缆槽，部分盖板可掀开 |
| 标识 | 墙上可能有简单的安全警示标识（中文），无装饰 |
| 白板 | 角落有一块小白板（S14/S15/S16/S17使用），比会议室的白板小，是辅助工具不是中心 |

## 色调与氛围

| 维度 | 描述 |
|------|------|
| 主色调 | 冷蓝灰（屏幕光）+ 深灰（墙面/地板）+ 黑色（设备） |
| 辅色调 | 极淡的青（数据可视化高亮）+ 暗蓝（阴影）+ 微白（屏幕文字） |
| 氛围 | 冷静、警觉、专注、不恐慌。是"深夜作战室"不是"红色警报"。空气里有咖啡、电子设备发热、以及长时间工作的疲惫 |
| 声音（暗示） | 机械键盘声、鼠标点击、服务器风扇、偶尔的电话铃声、低声讨论 |

## 半写实半水墨适配

> 风格分组：数据冷蓝（淡墨+花青，浓墨用于屏幕内容，大量暗部留白）

- **屏幕墙的"数据光"**：多块屏幕是空间中最亮的元素。用淡墨+花青表现屏幕的冷光，屏幕内容（曲线、数据）用略浓的墨+极淡的青，形成"信息浮现"感。不是画屏幕UI，是画"屏幕发出的光"
- **人物的"多源冷光"**：人脸被多块屏幕从不同方向照亮，形成复杂的明暗。水墨处理时，面部受光面用淡墨+微量花青，背光面用浓墨，交界处用清水破开。不是单一光源，是"被数据包围"的人
- **工作站的"技术线条"**：弧形排列的显示器形成重复的垂直线条。水墨处理时，用淡墨直线+枯笔边缘，表现工业秩序。线缆用极细的淡墨线，随意但不乱
- **服务器间的"暗"**：角落的设备间是最暗的区域。用浓墨+大量留白（留黑），仅门缝和设备指示灯有微光。指示灯用极小的高光点，不画灯泡，画"光点"
- **数据曲线的"漂移感"**：三条偏移曲线是34集核心视觉符号。水墨处理时，曲线用淡墨细线，缓慢偏移的轨迹用更淡的墨，形成"几乎看不见的变化"。不是画数据图，是画"漂移的痕迹"
- **禁止**：红色警报（本集拒绝恐慌视觉）、科幻全息（不是未来空间）、整洁明亮（是深夜作战室）、温暖色调（与会议室一样冷，但更蓝）

## 与深智科技会议室的区分

| 维度 | 安全中心（34集） | 会议室（25/36集） |
|------|-----------------|------------------|
| 空间功能 | 作战/分析 | 谈判/讨论 |
| 核心家具 | 弧形工作站+屏幕墙 | 长会议桌+白板 |
| 光源 | 屏幕光为主，环境极暗 | 顶灯均匀，窗户自然光 |
| 色调 | 冷蓝灰（更蓝） | 冷白灰（更白） |
| 人员姿态 | 站立/操作键盘 | 对坐/交谈 |
| 墙面 | 深灰吸音板 | 白色乳胶漆 |
| 时间感 | 深夜/凌晨 | 白天/傍晚 |
| 情绪 | 警觉/专注 | 博弈/疲惫 |
| 水墨关键词 | 淡墨+花青，暗部留白 | 淡墨+花青，大量白墙留白 |
