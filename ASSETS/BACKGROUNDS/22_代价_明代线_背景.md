# 第22集《代价》明代线 — 场景背景定妆规格

> **风格锚点**：`ASSETS/视觉总纲.md` — 灰青调（Qinghui），空寂与制度冷漠  
> **核心意象**：空织坊架子、灰尘在窗光中、皂角树灰绿不动、旧书碎片  
> **朝代约束**：明代（非清代），建筑、服装、器物必须符合明初形制  
> **与沈固/沈梁定妆的交互**：背景色调与人物"空"/"悲"情绪共振

## 场景3：织坊→皂角树的空间关联

> 明代线两个空间形成"内→外"、"空→悲"的递进：
> - 织坊是"被洗劫后的空"——封闭空间，灰尘，静止
> - 皂角树下是"被迫交出的悲"——开放空间，风动，人不动

| 对比维度 | 空织坊 | 皂角树下 |
|----------|--------|----------|
| 空间 | 封闭室内 | 开放室外 |
| 光源 | 窗光（微弱） | 天光（灰蒙） |
| 动态 | 灰尘缓慢飘浮 | 树叶被风吹动 |
| 人物姿态 | 蜷缩坐着 | 直直站着 |
| 情绪 | 空（无对象） | 悲（有对象但无力） |
| 色调 | 灰青 | 灰青+灰绿 |
| 水墨关键词 | 淡墨+花青，大量留白 | 淡墨+花青+微量赭石，枯笔风动 |

## 与角色定妆的交互约束

| 场景 | 角色 | 交互约束 |
|------|------|----------|
| 空织坊 | 沈固 | 人物与背景融为一体——灰袍+灰青环境，只有"空"区分人与空间 |
| 旧书碎片 | 沈固（目光） | 碎片在地上，他的目光不看碎片，看空——背景引导视线向上 |
| 窗光灰尘 | 沈固（剪影） | 逆光剪影，不画表情，画姿态——蜷缩的背是"空"的身体语言 |
| 皂角树下 | 沈梁+官员 | 官员的浓墨vs沈梁的淡墨=制度vs个人 |
| 皂角树远景 | 沈梁 | 人小树大，年轻人的悲在制度/自然面前渺小 |

## 与22集其他两条线的色调区分

| 维度 | 宋代线（陈圆） | 明代线（沈固/沈梁） | 美国线（鲍勃/多萝西） |
|------|---------------|-------------------|---------------------|
| 主色调 | 暖黄金 | 灰青 | 暖褪 |
| 光源 | 暖阳光/晨雾 | 窗光/天光 | 室内灯光/街灯 |
| 氛围 | 繁华→凋零 | 空→悲 | 踏实→悲凉 |
| 水墨风格 | 暖赭石+淡墨 | 花青+淡墨 | 淡赭+胶片颗粒 |
| 核心意象 | 石榴树 | 皂角树 | 苹果树 |
| 情绪弧线 | 骄傲→接受 | 空→悲 | 踏实→沉默 |
