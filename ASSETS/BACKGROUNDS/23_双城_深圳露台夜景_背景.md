## 核心元素详述

### 1. 露台（对话空间）

| 属性 | 描述 |
|------|------|
| 形态 | 高层露台，玻璃护栏，地面是石材或木质 |
| 家具 | 简单的户外桌椅，或两人站立倚靠护栏 |
| 光线 | 露台本身的灯光微弱，城市夜景是主光源 |

### 2. 深圳城市夜景（背景）

| 属性 | 描述 |
|------|------|
| 范围 | 从高处俯瞰，城市灯火延伸至地平线 |
| 色调 | 暖金+橙黄为主，点缀冷白（写字楼LED） |
| 层次 | 近景建筑清晰，中景灯火连片，远景淡化成光雾 |
| 标志性 | 可有深圳湾大桥、平安金融中心等轮廓，但不突出 |

### 3. 天空

| 属性 | 描述 |
|------|------|
| 颜色 | 深蓝→黑渐变，城市光污染形成的微亮 |
| 星星 | 几乎不可见（城市夜景） |
| 云层 | 可有薄云，反射城市暖光 |

## 半写实半水墨适配

> 风格分组：都市暖夜（淡墨+赭石+暖金）

- **城市灯火的"暖金晕染"**：远处的灯火不是清晰的灯泡，是"一片暖金"。水墨处理时，用赭石+藤黄+淡墨，边缘用清水破开，形成朦胧的城市光雾
- **露台的"暗部轮廓"**：露台本身在暗处，只画轮廓。护栏用淡墨线，地面用枯笔。人物面部被城市光从侧面照亮
- **夜空的"深蓝留白"**：夜空用淡墨+微量花青，从上往下渐变。城市灯光向上晕染，形成"光污染"的微妙过渡
- **两人的"夜景面光"**：面部被城市光从侧面/下方照亮，形成温暖的轮廓光。水墨处理时，亮部用赭石+留白，暗部用淡墨
