# 屏幕/界面设计规范 — 正式文档

> **版本**: v1.0  
> **适用范围**: 《超级智能2035》全剧涉及屏幕、界面、UI的所有镜头  
> **核心原则**: 界面是叙事的延伸，不是装饰。每一个像素都服务于情绪和信息的传递。

---

## 一、设计哲学

### 1.1 根本原则

| 原则 | 说明 | 反例 |
|------|------|------|
| **功能优先** | 界面首先服务于叙事功能（信息传递、情绪暗示） | 为了好看而添加的装饰性UI |
| **克制设计** | 去掉所有不必要的元素 | 过度设计的 futuristic UI |
| **一致性** | 同一系统在不同集次中保持视觉统一 | 同一APP在不同场景风格迥异 |
| **情感克制** | 界面不表达情感，只传递信息 | 情感化配色、动画、图标 |
| **时代真实** | 2030s中国的技术界面，不是科幻 | 全息投影、悬浮界面、透明屏幕 |

### 1.2 与AI不拟人化规范的配合

> AI不拟人化规范回答"不要什么"——不要人形、不要情感、不要人格化。  
> 本规范回答"要什么"——要简洁、要功能、要克制、要真实。

## 二、系统分类与规范

### 2.1 墨子系统（深智科技核心AI）

**出现集次**: 01/04/07/34/36/37

| 元素 | 规范 | 示例 |
|------|------|------|
| 主色调 | 冷白背景 + 深灰文字 + 淡蓝高亮 | 类似现代IDE的暗色/亮色主题 |
| 字体 | 等宽字体用于日志，无衬线用于界面 | Source Code Pro / Noto Sans |
| 布局 | 左侧导航栏 + 中央内容区 + 右侧状态栏 | 简洁的三栏布局 |
| 数据展示 | 表格、时间轴、纯文本 | 无图表动画、无3D可视化 |
| 日志界面 | 时间戳 + 事件类型 + 内容 | `04:32:17 [INTERCEPT] 异常检测触发` |
| 错误状态 | 灰色删除线或淡黄色标记 | 无红色警报、无闪烁 |

**关键界面类型**:

**a) AR眼镜界面（01集）**
```
[顶部状态栏] 时间 05:47 | 心率 72 | 情绪基线 0.3
[中央区域]   墨子分析窗口展开
[底部]       今日议程列表
```
- 半透明背景，不遮挡现实
- 文字清晰，信息密度适中
- 无动画效果，直接显示

**b) 交易决策界面（04集）**
```
[左侧] 卖方信息面板
[中央] 报价对比表格
[右侧] 墨子决策日志（滚动）
[底部] 操作按钮：确认 / 拦截 / 上报
```
- 决策日志是核心视觉元素
- 表格清晰，数值对齐
- 按钮标准样式，无特效

**c) 系统日志界面（34集）**
```
[顶部] 数据源分布图（六个月曲线）
[中央] 三条指标漂移曲线
[底部] 攻击路径五步图
```
- 数据可视化克制优雅
- 曲线用淡蓝/灰蓝，无红色
- 学术风格，不是好莱坞黑客界面

### 2.2 培训APP界面（37集）

**出现集次**: 37

| 元素 | 规范 | 说明 |
|------|------|------|
| 目标用户 | 中年再就业人群 | 字体偏大、界面简单、操作明确 |
| 主色调 | 浅蓝/白色 + 深灰文字 | 政府/公共服务类APP常见配色 |
| 字体 | 系统默认无衬线，字号16pt+ | 可读性优先 |
| 布局 | 单栏，大按钮，明确进度 | 类似驾考APP或学习强国 |
| 内容 | 汉字课程、拼音标注、简单测试 | 老张教李师傅认"参与" |

**关键界面**:
```
[顶部] 课程进度：第3课 / 共12课
[中央] 大字：参 与
       拼音：cān yù
       例句：参与其中
[底部] [播放发音] [下一个] [复习]
```

### 2.3 消息/聊天界面

**出现集次**: 多集（24集"已读无回复"、37集视频通话等）

| 元素 | 规范 | 说明 |
|------|------|------|
| 微信/类微信界面 | 标准聊天界面，绿色/白色气泡 | 中国观众熟悉的界面 |
| 已读标记 | 简单的"已读"文字 | 无动画、无特效 |
| 输入状态 | "对方正在输入..." | 标准省略号动画 |
| 视频通话 | 小窗口画中画，背景是房间 | 迈克37集的"过于整齐的公寓" |

**关键场景**:

**a) 24集"已读无回复"**
```
林薇："老师，你还好吗？"
[已读]
[无回复]
[时间显示：23:47]
```
- 屏幕光照亮林薇下半张脸
- "已读"两个字是情感核心
- 无动画，无提示音，只有沉默

**b) 37集迈克视频通话**
```
[小窗口] 迈克的脸
[背景] 旧金山公寓，过于整齐
[界面元素] 通话时长、信号状态
```
- 背景是"让人不安的整齐"
- 界面标准，不突出
- 迈克的神情是焦点

### 2.4 直播间UI

**出现集次**: 11/22/24等

| 元素 | 林薇直播间 | 周沫直播间 |
|------|-----------|-----------|
| 平台 | 专业直播设备 | 手机支架+简陋布置 |
| 界面 | 可能无UI（纯讲述）或极简UI | 手机自带直播界面 |
| 观众数 | 从47人到11人 | 可能更少 |
| 弹幕 | 极少或没有 | 无 |
| 风格 | 无商业感，像视频会议 | 更简陋，像自拍视频 |

**林薇直播间**:
- 重点在"讲述者"，不在平台
- 可能只有简单的录制指示灯
- 无美颜、无滤镜、无特效

**周沫直播间（11集）**:
- 白墙 + A4纸公式 + 小台灯
- 手机支架上的手机界面
- 可能显示观众数和点赞数
- 界面简陋，与林薇的专业设备形成对比

### 2.5 数据可视化界面（34集）

**出现集次**: 34

| 元素 | 规范 | 说明 |
|------|------|------|
| 数据源分布 | 六个月对比曲线图 | 单独看正常，拼在一起偏移 |
| 三条指标 | 平行漂移曲线 | 知识来源真实性、逻辑自洽性、价值判断稳定性 |
| 攻击路径 | 五步流程图 | 学术预印本→知识图谱→推理链→输出 |
| 配色 | 冷蓝/灰蓝/淡青 | 无红色、无警报色 |
| 风格 | 学术论文图表风格 | 清晰、克制、不戏剧化 |

**参考设计**:
```
[图表标题] 六个月数据源分布变化
[Y轴]    百分比 0-100%
[X轴]    月份
[曲线]   三条不同颜色的细线（蓝/灰/青）
[标注]   关键偏移点用淡黄标记
```

## 三、跨系统一致性

### 3.1 色彩一致性

| 系统 | 主色 | 辅色 | 高亮 |
|------|------|------|------|
| 墨子系统 | 冷白/浅灰 | 深灰 | 淡蓝 |
| 培训APP | 白色 | 浅蓝 | 深蓝 |
| 聊天界面 | 白色/绿色 | 灰色 | 无 |
| 数据可视化 | 深色背景 | 灰蓝 | 淡青 |

### 3.2 字体一致性

| 场景 | 字体 | 字号 |
|------|------|------|
| 系统日志 | 等宽 | 12-14pt |
| 数据展示 | 无衬线 | 14-16pt |
| 用户界面 | 无衬线 | 16-18pt |
| 培训APP | 无衬线 | 18-24pt |

### 3.3 动画一致性

| 效果 | 允许 | 禁止 |
|------|------|------|
| 数据刷新 | 淡入淡出 | 弹跳、滑动 |
| 页面切换 | 直接切换 | 翻页、缩放 |
| 加载状态 | 简单进度条 | 旋转图标、拟人化 |
| 状态变化 | 直接显示 | 闪烁、脉冲 |

### 4.1 历史线界面（19/21/22集）

| 场景 | 界面类型 | 说明 |
|------|----------|------|

| 40年代工牌 | 金属/纸质工牌 | 银白色，边角磨圆，无数字元素 |

|------|----------|------|

## 五、界面-叙事联动规范

| 叙事需求 | 界面响应 | 示例 |
|----------|----------|------|
| 林薇发现异常 | 界面显示"正常中的异常" | 34集：数据偏移但不警报 |
| 老张学字困难 | 界面字大但手指笨拙 | 37集：培训APP上的大字体 |
| 迈克视频通话 | 界面标准但背景异常 | 37集：过于整齐的公寓 |
| 林薇"已读无回复" | 界面静止，时间流逝 | 24集：屏幕光中的沉默 |
| 墨子决策过程 | 界面显示逻辑链 | 04集：决策日志滚动 |
