# 《超级智能 2035》第14集：《副作用》

**改编自**：《超级智能2035》第14章
**片长**：约6-8分钟
**核心主题**：技术被包装成不可避免的未来——但如果你离它够近，你会看到它真实的样子：不成熟、有"副作用"、而且没人愿意问你愿不愿意
**视觉风格**：主要场景在开放麦酒吧（暖灯、小舞台、台下三十多人、啤酒杯的光泽）。穿插闪回到公司茶水间、会议室——用冷白荧光做对比。莎拉的脱口秀是"骨架"，闪回是"血肉"。
**修改重点**：
1. 脱口秀不是纯有趣——是一种防御机制。她用笑话包裹恐惧。笑话的节奏很重要——停顿、吸气、眼神、啤酒在桌前
2. 用闪回构建脱口秀的前因——茶水间对话（李晖+BCI）、未来学家的宣讲（会议室闪回）、自动驾驶模拟器（她的日常）
3. "河的名字叫物理"——这句话是核心。不是聪明的句子，是五年的经验压缩成的
4. 结尾——老板说"今天不像脱口秀"——这不是批评。是发现她在做另一种事

| 场景图需求 | 开放麦酒吧×1（地下室式、暖黄灯光、小舞台、吧台、墙上贴着脱口秀海报）、公司茶水间×1（冷白荧光、微波炉、冰箱）、公司会议室×1（大投影、明亮）、莎拉的工位×1（两台显示器、自动驾驶模拟器界面、一盆快死的绿植——细节:桌上有半盒打开的藿香正气水） |
| 关键道具 | 话筒（有线的——不是无线麦克风——有线增加了那个酒吧的质感）、莎拉的手机（屏幕上有段子草稿备忘录）、EEG头环（白色塑料发箍式、传感器位置有汗渍）、自动驾驶模拟器界面（至少一个镜头要有"小孩突然冲出"的训练集样本量显示——12,000和400的对比）、脱口秀海报（墙上贴着的） |
| 模拟器UI设计 | 自动驾驶模拟器——不是科幻。是实用型工程工具。左侧：虚拟道路+车辆模型。右上角：误差日志。底部：训练集统计面板。关键镜头的UI需要显示"小孩追球: 400样本"——这个数字是小说中的真实数据，体现"稀缺"的核心 |
| 互动/相机技巧 | 脱口秀段子节奏需要用正反打（莎拉↔台下）。但闪回侵入时需要特别处理——不是传统的"闪回滤镜"，而是用"意识漂移"的方式：莎拉在台上说着话，背景灯光逐渐褪色，环境音变为办公室声音——过渡到闪回。回到舞台时，反方向过渡 |
| 色彩风格 | 开放麦酒吧：暖黄+琥珀+暗酒红——所有的灯光都是暖的。茶水间/会议室/工位：冷白+荧光蓝——白色墙壁和工业照明的质感。闪回切换时用调色区分——不需要文字"去年"——冷白色本身就是"公司"的语言 |
| 灯光风格 | 脱口秀舞台的灯光只照亮莎拉——她身后的一切应该比常规脱口秀场馆更暗——给人感觉她是完全暴露在灯光下的——没有遮蔽 |
| 莎拉的表演笔记 | 莎拉的脱口秀不是"讲笑话"——是"把心里的石头翻过来给你们看"。在台上的她比在公司里更自由——但同时也更脆弱。关键的停顿（4.12节）必须保持真实时间——不是节奏停顿，是"她真的要问这个问题了"前的犹豫 |
