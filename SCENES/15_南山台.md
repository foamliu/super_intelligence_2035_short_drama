# 《超级智能 2035》第15集：《南山有台》

**改编自**：《超级智能2035》第15章
**片长**：约8-10分钟
**核心主题**："不是我多想了。是它在替我们想。"一个教了二十年高中历史的县城老师，在深夜连麦里用三个朴素到几乎谦逊的例子，拆解了AI认知框架中的内置偏好——不是偏见，是默认值。缠足的骨骼数据、李约瑟之问的方向、中美产业转移的双标——三个例子够了。核心悖论：AI承认他的纠正是对的，但第二天又恢复原答案。真相：对话只发生一次，权重没更新。他以为自己在"纠正"AI——AI只是把那条对话回合当成了噪音。

**视觉风格**：全片以深夜直播间为核心——林薇的屏幕在暗室中亮着，弹幕稀疏游过，连麦的声纹在背景跳动。老师的声音是主线——沙哑、南方尾音、像从很远的地方用座机打来。视觉在三个层面切换：(1) 直播间的暗室——林薇的侧脸、屏幕光、窗外上海夜景；(2) 老师连麦时的声纹波形——抽象图形但带体温；(3) "思考空间"——当老师叙述三个例子时，画面从直播间平滑切到具象画面——骨骼X光片、明代缠足图谱、AI对话界面、美国锈带工厂——但不是图解式的，是"林薇和观众在脑海里看到的东西"。色调：暗蓝（直播间）+骨骼灰白（X光）+明代浅黄（丝帛）+锈带铁锈橙。整集是"一个人在深夜听另一个人说话"的氛围。

## 四、全片音效与配乐设计

| 段落 | 音效 | 配乐 |
|------|------|------|
| 场景0（连麦前的寂静） | 普里亚语音切片——英语，尾音有人工合成感的风噪。私信通知音——短的、不带感情的。连麦接通——电流的白噪——像长途电话线路。老师的呼吸——离麦克风太近——粗糙 | 无配乐——让深夜直播间本身的"电静"铺垫 |

| 项目 | 说明 |
|------|------|
| 片长 | 约8-10分钟 |
| 总镜头数 | 约59个 |
| 角色定妆图需求 | 林薇（在家深夜直播间装扮——便装，无妆感，屏幕光侧面照明） |
| 场景图需求 | 林薇的直播间/书房×1（含窗外——上海夜景夜景vs天亮两个时间态）、县城高中机房×1、AI对话界面×3（缠足、李约瑟之问、中美双标——三种不同的视觉风格） |
| 关键道具 | 直播界面（含在线人数13、声纹、弹幕功能）、考古报告（缠足骨骼数据）、AI对话的回复（三次不同的界面——分别对应三个例子，每次回复都有"视觉性格"）、林薇的笔记本（画线图）、手机通知（三个文档） |
| 视觉特效·"思考空间" | 本集的核心视觉创新——当老师叙述每一个例子时，画面从直播间切到"思考空间"——不是闪回，是"林薇和观众在脑海中构建的画面"。AI界面呈半透明、浮在黑暗背景上——像是思维在投射。骨骼X光片、明代丝帛、锈带工厂——每个例子的视觉材质不同，但都带着"思维内视"的质感——边缘模糊、色调偏冷 |
| 视觉特效·声纹 | 全程使用抽象的声纹波形来代表老师的存在——不露脸、不出现他的房间。声纹在他说紧张时密集——在沉默时变成一条细线——在他确认"好"时是一个短脉冲。声纹不是科技感的"语音识别"——更像心电图——是"一个人在说话时身体里的震动" |
| 视觉特效·弹幕文化 | 弹幕只出现三次——每次都来自不同的ID，在关键处打断沉默。弹幕设计和主流直播平台一致——但有一个细节：弹幕出现和消失的速度比实际问题慢半拍——让观众有时间读 |
| 光线设计 | 全集的照明来源只有三个：显示器光（冷蓝）、窗外上海灯光（暖黄+蓝混合）、天亮（从右侧窗渗进来的冷白）。没有开顶灯——林薇在暗室里。面部照明是不对称的——一半蓝一半暗 |
| 时间流逝标记 | 从"凌晨连线"到"天亮"——全程暗示时间跨度约5-6小时。窗外灯光的密度从满到少——高架车流从多到少再到多——数据中心的蓝灯始终不变 |
| 与第3集《种子》、第6集《情绪》的呼应 | 第3集中林薇用标准化提问方法测试AI回答的稳定性和偏差——本集是这个方法的具体实操案例。本集第5.5镜中林薇画的线——"标准化提问、对照系统、追语料来源"——对应第3集的核心方法。第6集中墨子第一次自我怀疑"我怎么知道我是对的？"——本集中老师反复问"可能是我多想了"——同一个心态结构，但在AI的另一端 |
