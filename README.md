## 四、统一视觉风格

### 总体原则

- **现实质感**：不追求过度科幻感，保持日常光影与细节
- **人物审美**：俊男美女，符合短剧市场主流审美，但保持自然感（非网红脸/过度磨皮）
- **低饱和度**：整体偏灰、偏冷（历史章节除外）
- **固定画幅**：统一16:9

### 人物审美标准

| 维度 | 标准 |
|------|------|
| 颜值 | 俊男美女，符合主流短剧审美 |
| 妆造 | 自然裸妆，不夸张，贴合角色身份 |
| 质感 | 保留皮肤纹理，不追求过度磨皮 |
| 气质 | 贴合角色设定（研究员有书卷气，工人有劳动感，老人有岁月痕迹）|

### 审美优先级建议

"短剧市场审美"与"自然质感/保留纹理"存在天然张力。建议按场景类型分档处理：

| 优先级 | 场景类型 | 处理策略 |
|--------|----------|----------|
| **质感优先** | 老工人（王建国）、老人（赵淑芬）、出租车司机（老周）、非洲诊所（奥蒂诺） | 保留皮肤纹理、皱纹、汗渍，强调真实劳动感——这本身就是这类角色的视觉说服力 |
| **平衡** | 主角中景对话（林薇、陈思危、墨子界面） | 自然光感 + 适度美化，不过度磨皮但确保"上镜感" |
| **审美优先** | 直播间出镜（林薇、周沫）、历史美人（陈圆）、跨文化精英（莉娜·陈） | 可适度提升面部平整度和光影柔和度，因为这符合角色所处场景的视觉逻辑（直播自带滤镜、宋代审美理想化、精英形象管理） |

> **核心原则**：不搞全局统一磨皮。让审美策略**服务于场景说服力**，而非反过来。

## 五、角色一致性技术路线

跨镜头、跨章节的角色面部一致性是AI生成短剧的核心难点。以下技术路线用于锁定同一角色在不同画面中的外观。

> ⚠️ **人像一致性风险评级：中等（无商用级确定性方案）**
> 
> 当前方案（IPAdapter + FaceID + 关键词锁定）是开源工具链中性价比较高的路线，但**无法保证同一角色跨镜头的面庞精确一致**。这意味着：
> - 每镜需生成 4-6 张候选、人工筛选，后期筛片成本占 T2I 总工时 20%-40%
> - 同一角色在不同镜头间可能出现"像但不确定是不是同一个人"的偏差
> - 长剧集中人物一致性的工程瓶颈是当前 AI 视觉制作的核心未解决问题
> 
> **协作预期**：协作者需建立"80 分一致性"的合理预期——目标是在给定场景/光影条件下保持风格和大致面貌的统一，而非像素级的身份锁定。商业级方案（专有模型 + 角色 LoRA 精调 + 多轮人工修图）不在本项目开源工具链范围内。

### 定妆流程

1. **初稿生成**：对角色首次出现的镜头，T2I 批量生成 6-8 张候选（正面、半侧面、不同表情）
2. **筛选定稿**：人工选出最佳定妆照，确保五官清晰、气质贴合角色设定
3. **入库**：所有角色定妆参考图统一存入 `ASSETS/CHARACTERS/{角色名}/`，不分常驻/章节角色

### 一致性控制工具

| 工具 | 用途 | 适用场景 |
|------|------|----------|
| IP-Adapter + FaceID | 用定妆参考图锁定面部特征 | 所有含角色的 T2I 生成 |
| 角色 LoRA | 针对高频角色训练轻量 LoRA | 常驻主角（贯穿多章的角色）|
| 定妆参考图直输 | I2V 阶段以定妆照作为起始帧 | 关键对话镜头、特写 |

### 跨章节一致性策略

- 所有角色定妆参考图统一存放于 `ASSETS/CHARACTERS/{角色名}/`
- 每章开拍前，从 `ASSETS/CHARACTERS/` 拉取所需角色定妆照，作为该章 T2I 的 IP-Adapter 输入
- 若某章角色外观需随剧情变化（年龄、着装），在对应角色目录下追加变体参考图（如 `林薇/林薇_2035春.png`），并在分镜脚本中标注

## 七、分镜脚本规范

### 7.1 文件与命名

全 42 章**单章单文件**，命名 `SCENES/<NN>_<标题>.md`（`NN` 为两位章号 01–42，连续无缺）。

```
SCENES/
├── 01_晨钟.md
├── 02_经验.md
├── ...
└── 42_夜巡.md
```

> **命名约定**：文件名沿用既有工程编号（`NN_<中文短名>.md`），与原著章节名可能略有差异，例如 `11_极速ASI.md` ↔ 原著第11章《速度型ASI》、`38_棋局.md` ↔ 《棋盘》、`42_夜巡.md` ↔ 《守望》。**章名以文件内 H1 与 `| 来源 |` 字段为准**（与 `chapters_v1_1/` 原著一致）。

每个文件自上而下固定五段（段名与顺序不得改动）：

| 段 | 内容 |
|----|------|
| ① 标题 | `# 第N章：《标题》 — 分镜脚本` |
| ② 元信息表 | 来源 / 片长 / 镜数 / 单镜时长 / 核心场景 / 主要角色 / 核心主题 / 视觉基调 |
| ③ 逐镜表 | `## 逐镜表`，按原著小节分组的多个 7 列表格 |
| ④ 关键镜 Prompt 指引 | 挑 3–6 个关键镜，给可直接投喂 T2I/I2V 的中英文 prompt（含外观、动作、光照、色调、写实质感、16:9） |
| ⑤ 结尾引文块 | 制作约定（指向本 README）+ 下一章钩子（终章改为「全书终」主题句） |

### 7.2 逐镜表列定义

表头**顺序固定**，不得增删改列：

| 列 | 含义 | 取值约束 |
|----|------|----------|
| 镜号 | 章内唯一编号 | 1…M 连续，无空号、无跳号 |
| 时长 | 生成时长 | 整数秒，**2–10 s**；有台词按字数给足，无台词反应镜 2–3 s，转场/字幕镜 4–6 s |
| 画面 | 可见内容 | 主体 + 动作 + 光 + 环境；只写"看得见"的东西 |
| 运镜 | 摄影机运动 | 仅限 **固定 / 缓推 / 缓拉 / 缓慢横移 / 横摇 / 跟移 / 手持轻微**（可括注补充） |
| 景别 | 取景范围 | 仅限 **远景 / 全景 / 中景 / 中近景 / 近景 / 特写** |
| 台词/音效 | 台词·旁白·音响 | 说话人 `角色：`，旁白 `角色（VO）：`；音效统一 `音效：xxx（后期）`；忠于原著、不编造 |
| 参考图提示 | 所需参考素材 | 单人 → `角色名定妆照 + 场景参考`；纯场景 → `场景参考（T2V）`；多人同框 → `角色A+角色B + 场景参考` |

### 7.3 景别标准

### 7.4 制作约定（跨章通用）

1. **一个镜号 = 一次视频生成**（T2V 或 I2V）；表内时长即该次生成时长。
2. **音效不占生成时长**：所有标 `（后期）` 的音响、环境音、BGM 由后期叠轨（见 §十）。
3. **角色外观以 §二 角色定妆表与 `ASSETS/CHARACTERS/` 定妆照为准**；跨章复用同一定妆照，需变化时在角色目录追加带日期变体。
4. **镜号章内连续、跨章重新计数**；产物按 `EP{NN}_SHOT-{MM}`（如 `EP13_SHOT-01`）命名。
5. **历史/异域章节差异化色调**，见 §四「时代/地区色调」。
6. **章间钩子**：文末 `> **下一章**：第N+1章《标题》` 须与下一章实际标题一致；终章改为 `> **全书终**`。

> 素材库推荐：Freesound（CC0 许可）、BBC Sound Effects（非商业免费）。所有外采音效统一存放于 `ASSETS/AUDIO/` 并按场景编号命名。

### 混音流程

```
┌──────────────────────────────────────────────────┐
│ 1. 对白/旁白（Qwen3-TTS）→ 主干音轨             │
│    - 统一归一化到 -23 LUFS（响度标准）            │
│    - 降噪、去齿音处理                             │
├──────────────────────────────────────────────────┤
│ 2. 环境底噪 → 连续铺底                           │
│    - 每场景独立铺设，跨镜头连续不中断             │
│    - 音量拉至 -28 ~ -32 LUFS，不抢主干           │
├──────────────────────────────────────────────────┤
│ 3. 配乐（ACE-Step 1.5）→ 情绪引导轨             │
│    - 仅在需要情绪提升的段落加入                   │
│    - 淡入淡出 ≥ 1 秒，避免突兀切入               │
│    - 音量控制在 -25 ~ -30 LUFS                    │
├──────────────────────────────────────────────────┤
│ 4. 重点音效 → 定点放置                           │
│    - UI 交互音、关键动作音按帧精准对齐            │
│    - 峰值不超过 -12 dBFS                          │
├──────────────────────────────────────────────────┤
│ 5. 母带 → 响度标准化 + 动态控制                  │
│    - 整体输出 -23 LUFS（YouTube/Vimeo 标准）      │
│    - 峰值限制器 -1.0 dBTP                         │
└──────────────────────────────────────────────────┘
```

### 字幕生成策略

| 环节 | 工具/方式 | 说明 |
|------|-----------|------|
| **旁白/台词文本** | 分镜脚本直接导出 | 脚本中的台词/旁白即为字幕源文本，无需额外转录 |
| **时间轴对齐** | DaVinci Resolve 自动对齐音频 | 导入语音音频后利用 Resolve 语音识别功能自动打时间轴 |
| **字幕格式** | SRT（标准外挂字幕） | 编码 UTF-8，与成片封装一同交付，也支持软字幕开关 |
| **双语字幕** | 分镜脚本提供英译 | 每集脚本预留英文台词栏位（可选），满足国际发行需求 |
| **风格统一** | ASS 样式模板 | 白字黑边/半透明底，字体思源黑体 Medium，字号匹配 1080p |

> 字幕 QC：每集成片导出后，以 1.5 倍速通读字幕文件，检查时间轴偏移（阈值 ≤ 0.3 秒）、错别字、标点残漏。

### 13.2 API 调用通用模式

所有工作流通过 ComfyUI REST API（默认 `http://127.0.0.1:8188`）调用：

```python
import json, time, uuid, urllib.request

COMFYUI = "http://127.0.0.1:8188"

# 1. 加载 workflow 模板
wf = json.load(open("workflows/xxx.json", encoding="utf-8"))

# 2. 注入参数（按 class_type 匹配）
for node_id, node in wf.items():
    ct = node.get("class_type", "")
    if ct == "KSampler":
        node["inputs"]["seed"] = 42
        node["inputs"]["steps"] = 8
    elif ct == "SaveVideo":
        node["inputs"]["filename_prefix"] = "output/my_shot"
    # ... 按需修改各节点

# 3. 提交
data = json.dumps({"prompt": wf, "client_id": str(uuid.uuid4())}).encode()
req = urllib.request.Request(f"{COMFYUI}/prompt", data=data,
                             headers={"Content-Type": "application/json"})
with urllib.request.urlopen(req, timeout=30) as r:
    prompt_id = json.loads(r.read())["prompt_id"]

# 4. 等待完成
while True:
    r = urllib.request.urlopen(f"{COMFYUI}/history/{prompt_id}")
    h = json.loads(r.read()).get(prompt_id, {})
    st = h.get("status", {}).get("status_str", "")
    if st == "success" and h.get("outputs"):
        break
    if st == "error":
        raise RuntimeError(f"Prompt failed: {h}")
    time.sleep(2)

# 5. 下载
for nid, node in h["outputs"].items():
    for img in node.get("images", []) + node.get("audio", []):
        fn = img["filename"]; sub = img.get("subfolder", "")
        typ = img.get("type", "output")
        url = f"{COMFYUI}/view?filename={fn}&subfolder={sub}&type={typ}"
        urllib.request.urlretrieve(url, f"OUTPUT/{fn}")
```

## 十四、质量验收标准

每个章节成品在进入后期剪辑前，需通过以下质量门禁：

| 检查项 | 通过标准 | 不通过处理 |
